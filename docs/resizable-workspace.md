# 等高与可调宽度的桌面工作区

桌面宽度超过 1000 像素时，左侧空间、中间对话、右侧学习栏共用同一高度，上下边缘对齐；内容超出时在各自栏内滚动。聊天区占据中栏剩余空间，输入框仍紧凑，不因侧栏内容变多而增长整行高度。

两条分隔线支持鼠标或触控拖动，也支持 Tab 聚焦后用左右方向键微调（Shift 加速）、Home/End 到达最小/最大宽度；双击分隔线或点击左下方“恢复默认布局”可恢复。中间阅读区至少保留 320 像素；左栏 150–310 像素，右栏 210–380 像素，实际可调整范围还受窗口宽度限制。拖动时尽量保留当前阅读位置。

当前浏览器只保存两项栏宽数字，不保存对话或个人资料；禁止本地存储时仍能调整。较窄窗口和手机保留原响应式上下布局，不显示拖动柄，不强制三栏等高。

本步仅调整前端布局，不更改账户、资料、聊天或教案数据。开发检验使用独立模拟页面，不调用真实 AI 或邮件服务。
