# 等高与可调宽度的桌面工作区

桌面宽度超过 1000 像素时，左侧个人空间和聊天区共用同一高度、上下边缘对齐；内容超出时在各自栏内滚动。聊天区占据左栏之外的剩余空间，输入框仍紧凑，不因左栏内容变多而增长整行高度。完整学习进度和续学动作在“我的学习”中处理。

左侧分隔线支持鼠标或触控拖动，也支持 Tab 聚焦后用左右方向键微调（Shift 加速）、Home/End 到达最小/最大宽度；双击分隔线或点击左下方“恢复默认布局”可恢复。聊天阅读区至少保留 420 像素；左栏默认 240 像素、可在 190–360 像素间调整，实际范围仍受窗口宽度限制。拖动时尽量保留当前阅读位置。

当前浏览器只保存左栏宽度，不保存对话或个人资料；禁止本地存储时仍能调整。较窄窗口和手机保留原响应式上下布局，不显示拖动柄，不强制两栏等高。

本步仅调整前端布局，不更改账户、资料、聊天或教案数据。开发检验使用独立模拟页面，不调用真实 AI 或邮件服务。

## 检验记录

两栏版本的聊天、学习、资料和重温定向回归通过，JavaScript 语法检查通过。自动检验确认右侧学习栏不再输出，当前主题或资料以输入框上方紧凑状态呈现，“我的学习”仍保留继续学习路径，左栏的拖动、键盘调整与恢复默认逻辑仍由同一脚本处理。所有页面检验使用虚构账户，不调用真实 AI 或邮件；实际桌面和手机视觉尺寸仍应在个人试用时复核。
