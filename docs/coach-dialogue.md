# 统一对话与可继续的学习位置

当前持续入口支持 [本机完整备份、检查与新目录恢复](local-backup.md)。操作前先停止服务；新版服务运行期间持有目录锁，防止同一空间被另一服务或备份同时使用。个人阅读导出继续保留。

## 本步效果

聊天、主题学习、围绕资料讨论都使用同一个对话框。对话页不再固定占用右侧学习栏：当前对话已明确关联主题时，输入框上方显示“正在学习”；当前对话没有主题时，显示最近一次“上次学习”及“点击切换”按钮，只有用户点击才切换。已选资料或正在重温教案也以紧凑状态呈现，并可进入“我的学习”。学习进度、下一步、选段和“继续学习”统一在“我的学习”中查看和操作；临时换话题不清除原学习记录。进度是教练根据已讨论内容整理的记录，不是掌握程度百分比，也不要求用户填写评分表。

对话、学习记录按登录账户隔离，保存在本机独立数据库 `coach_conversations.db`，退出、重新登录和重启后仍保留。聊天区独立滚动，打开时定位最新内容，每批加载 40 轮（一条用户消息及其回复为一轮）；向上滚动到顶部时继续加载更早记录，也可点击加载按钮。后台不按 40 轮截断或自动清除记录，实际容量受本机磁盘空间限制。单次输入最多 2000 字，教练回复最多保留 12000 字。查看历史不调用 AI；发送给 AI 的上下文最多最近 10 轮、16000 字，加上独立学习记录。本步提供基础续学记忆；完整长期个人画像和知识检索仍待接入。

现已接通资料上传、选择、片段检索和教案确认保存。已选资料会在输入框上方显示名称和选段，回答旁展示真实引用；未选资料时不额外占用对话空间。用户可要求整理教案，Coach 也可提出草稿；用户预览、可修改后点击确认，才进入知识库。已保存教案可导出或回到同一对话重温。参见 [资料与教案说明](materials-and-knowledge.md)。

页面不再显示账户就绪横条，桌面为“左侧个人空间 + 扩大的聊天区”两栏；左栏可拖动调整宽度。对话页顶部仅保留知行与“了解知行”，聊天区上沿与品牌区域对齐；输入区不再放置“回到最新对话”按钮。输入区保留当前服务状态和 AI 用量入口，详细学习与续学入口集中在“我的学习”。加载更早历史时保持当前阅读位置，网络失败保留已显示内容并提供手动重试。

## 本机启动

2026-10-21 更新：日常默认端口为8785，模拟仍为8784；默认目录保持不变。日常操作以[固定入口](daily-use.md)为准，以下保留该功能阶段的说明。

仅本机试用，不用于公开部署。旧 `api.run` 和临时账户工具继续保留；持续使用请选新入口。

```powershell
Set-Location 'D:\Personal-Growth-Coach'
python -m api.coach_run --simulate
```

打开 `http://127.0.0.1:8784/web/register`，使用虚构资料注册，点击模拟发信，再到 `/web/trial-mailbox` 打开模拟邮件确认。登录后输入“我想学习时间管理”，再聊其他话题，点击“继续上次学习”。模拟回复明确标注，不调用 SMTP 或 AI。模拟记录保存在 `data/coach-simulated`。

真实本机首次持续试用：

```powershell
python -m api.coach_run --register --ai
```

终端输入本人 163 邮箱和隐藏的客户端授权码；只允许向该本人邮箱发信，仍由用户在网页点击发送。AI 使用现有 `.env` 配置，仅点击“发送”或“继续上次学习”时调用，可能产生 API 费用；`LLM_TIMEOUT` 需为 1–60 秒。不在聊天中提供密钥或授权码。授权码仅保留于当前进程。

账户与对话保存在 `data/coach-local`，已加入 Git 忽略。此前 `api.account_test` 创建的是临时账户，无法自动沿用，需在持续数据空间重新注册一次。之后启动不再需要邮箱授权码：

```powershell
python -m api.coach_run --ai
```

不加 `--ai` 时可登录查看已有记录，不发起 AI 请求。不加 `--register` 时不提供真实发信。`--port` 可换端口；`--data-dir` 指定独立目录。模拟与真实模式不可混用同一已标记目录。停止后数据保留，请自行保管本机数据和备份；已支持教案导出，资料删除和跨设备同步后续补充。

## 检验边界

自动化验证使用模拟邮件和注入的假 AI，不发送真实邮件、不调用计费接口。真实 AI 的回答质量与主题识别需要用户后续实际体验；模型未输出有效学习摘要时保留原记录。用户输入仍以转义纯文本显示；教练回复、分页历史和教案预览使用同一安全 Markdown 排版，支持标题、表格和保留缩进的代码框，不执行原始 HTML 或代码，不加载远程图片。

请求按服务端登录身份归属，禁止表单指定用户；发送与续学均校验 CSRF 和来源，限流、限制长度与并发。同一提交标识最多调用一次，同一账户串行处理。失败保留用户消息并提示；不会自动重试。不确定中断最多等待 180 秒后标为失败，迟到回复不能覆盖新记录。系统不保存原始提供商异常，不向网页暴露密钥或数据库细节。

旧的按用户编号访问的开发路由没有挂载到此入口。后续已提供本人邮件密码找回、个人导出和本机整库备份；公开商用之前仍需完善部署、数据管理、隐私说明及运营限制等工作。
