# 对话窗口

统一对话工作区现在支持多个本人对话窗口。它解决的是“想换一个新主题，但不想在旧聊天记录里继续”的使用场景；它不删除任何历史记录，也不替代学习主题目录。

## 使用方式

1. 在对话区顶端点击“＋ 新开对话”。中间聊天区会立即清空，右侧不再带入上一窗口的学习主题或资料。
2. 第一条消息会成为这个窗口的本地标题，不调用 AI；后续可在“最近对话（可切换）”中重新打开。
3. 打开旧窗口时，原有聊天记录会显示；若该窗口关联过学习主题，会同时恢复对应的主题、进度和资料位置。
4. 从对话输入框的“＋ 添加资料”会进入独立添加页；在其中上传 PDF、TXT、Markdown 或粘贴文字后，资料会自动选入当前对话并返回聊天。输入区会显示“已上传并选入《资料名》”，随后直接提问即可由 Coach 检索真实片段；不需要再到资料目录重复点击“围绕这份资料讨论”。

“新开对话”仅切换当前窗口，不会删除旧窗口、教案、资料、学习主题或学习记忆。教练正在回复、或用户正在重温教案时，按钮会暂不可用，防止把一轮未完成的回复放错窗口。

## 上下文与数据边界

- AI 只会获得当前窗口中的近期对话；新窗口不会暗中带入旧窗口的聊天内容。
- 同一窗口内继续某个学习主题时，临时闲聊不会成为该主题的近期上下文。
- 既有账户升级时，旧聊天记录被完整保留在一个名为“历史对话”的窗口，不自动猜测拆分。
- 窗口、标题和历史记录按账户隔离，切换或新建本身不调用 AI。
- “资料与书籍”页面只负责查看、阅读、查找、改名和选择已保存资料；上传与粘贴集中到独立的“添加资料”页面，避免混杂操作。

当前列表显示最近 21 个窗口；记录没有在此功能中自动删除。更早的对话仍可通过原有对话记录和检索功能查找。
