# 旧开发入口

`python -m api.run` 默认在 `127.0.0.1:8000` 启动早期开发页面，使用项目 `data` 目录，包含保留的旧学习流程和内部接口。该入口的登录预览仍禁用，与当前账户空间不同。它不适合作为本人日常试用或公开注册入口。

日常使用请按[固定入口](daily-use.md)执行 `python -m api.coach_run --ai`。不要为了切换入口复制或覆盖旧数据库；没有自动将早期临时测试账户迁入持续账户空间。

开发者如确实需要旧流程，可执行 `python -m api.run --help`，并指定独立测试目录与端口。项目首页说明以当前 README 为准；Git 历史保留过去阶段的详细记录。
