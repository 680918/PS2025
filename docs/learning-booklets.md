# 我的学习手册：把已保存教案成册

在左侧知识资产沉淀或知识库中打开“我的学习手册”，创建一本手册，查找并收录本人已经确认保存的教案。可以按主题、书籍或个人目标组织内容，用上移、下移调整顺序，移出后原教案仍然保留，也可以重新收录。草稿必须先确认保存，不能借助手册自动入库。

手册只保存名称、章节顺序和教案编号，不再复制正文。当前每账户最多 50 本手册，每本最多 100 章。同一教案可属于多本手册，同一本不会重复收录。阅读时一次只展开一章，并显示当前教案版本、整理时的来源和单元范围；目录可跳转，支持上一章、下一章和在统一对话中重温当前章。手册引用最新的已保存教案版本，原教案修订和版本恢复机制继续保留。

每本手册可导出整册 HTML 阅读版或 Markdown。HTML 含目录跳转、安全 Markdown 排版和引用，下载后可离线阅读；个人 ZIP 导出增加独立“学习手册”选项，整册使用导出事务当时的一致版本。手册版本是目录编辑版本，不等于每章的教案内容版本。导出副本不随后续线上修改自动变化，不提供账户恢复或共享链接。

创建、收录、排序、阅读、查找和导出均不调用 AI。只有用户回到统一对话主动提问或重温时，才使用原有 AI 功能。目录修改不改变学习主题、进度、资料选择或原教案；读取、导出和章节重温都按账户核对原教案归属。原教案若不可用，显示占位提示，不回退到其他教案。

新增一张小表，沿用既有 SQLite 仓储、账户和知识资产流程，无新依赖或后台任务。目录写入在事务内核对版本、教案归属和保存状态；多页面冲突不覆盖当前目录，名称修改保留本次填写并要求核对后再次保存。表单与会话、手册、目录版本、操作和教案编号绑定；移出是可逆的目录调整。旧数据库的只读导出不要求新表。

本阶段按用户 2026-10-18 的自主开发授权推进：检验通过后直接提交并同步开发分支，交付可体验结果。真实 AI 的讲解质量仍需本人体验，本功能本身不新增 AI 请求。
