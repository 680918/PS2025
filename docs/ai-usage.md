# AI 用量与每日受理上限

左侧“AI 用量”显示当前账户今日已受理次数、个人每日上限，以及最近七天按“聊天、续学与对话教案”和“书籍单元教案”分类的记录。默认每账户每天 100 次，本成长空间每天合计 500 次；按北京时间每日零点进入新一天，重启、退出或更换端口不会清零。

这是本机试用的请求受理次数保护，不是实际账单或金额预算。一次受理对应一次主动交流或整理请求，不按 token、内容长度或底层 HTTP 次数计算。从本功能启用后开始记录，不倒推历史 AI 调用；模拟回复也记录，模拟与真实模式使用各自独立数据目录。

## 共同受理与失败边界

普通聊天、续学、选段讲解、对话中生成教案、书籍单元整理共用一份持久计数。次数分配与该轮消息、主题和选段绑定在同一个 SQLite 写事务中，先核对本人及全空间额度，再记录请求。多个账户同时抢占最后额度不能超发；同一 nonce 的重复提交、忙碌、校验失败和超额拒绝不重复分配次数。

已经受理的请求发生异常、无效回复、超时或进程中断时保守保留次数，不自动退回或重试。准备上下文过程中失败、尚未送达服务商的请求也可能占用一次；不能据此断言已计费。真实金额和调用明细以服务商为准，本工具不读取账单、余额或密钥。

达到上限时不调用 AI，不新增该轮聊天或切换其学习主题和选段。普通聊天页面明确提示尚未受理、保留输入并恢复操作按钮，移除临时显示的未发送气泡；网络或其他不确定错误继续使用原来的保守提示，避免重复发送。普通表单和主题续学、单元整理也显示拒绝原因。

阅读、查找、上传、教案手动修订、确认保存、导出和管理已有资料不占用次数。明确“请记住……”的学习记忆保存继续在系统内完成，即使 AI 额度暂停也不调用模型、不计数；未启用 AI 的服务仍可从记忆管理页面操作。

网页只显示当前账户的计数；达到共用额度时给出通用提示，不展示其他账户身份、消息或用量明细。用量表只存账户编号、随机请求编号、日期、用途和受理时间，不额外保存对话、原文或密钥。读取用量不修改聊天、进度或计数。

## 本机维护者调整

提供独立工具，只操作已经使用的成长空间，不创建新账户或新数据目录。正常服务可继续运行，SQLite 事务让后续请求读取最新设置；已经受理的请求继续完成。普通网页不能提高额度。

```powershell
Set-Location 'D:\Personal-Growth-Coach'
& 'C:\BCtools\anaconda3\python.exe' -m api.coach_usage show
& 'C:\BCtools\anaconda3\python.exe' -m api.coach_usage set --per-user 100 --total 500
```

默认目录为 `data/coach-local`，其他已有空间加 `--data-dir`。个人上限支持 0–10000，全空间支持 0–1000000；两项都非零时全空间上限不能小于个人上限。必须同时填写两项，避免不完整调整。设为 0 暂停相应 AI 受理，需维护者提高上限后恢复，不承诺第二天自动解除暂停。调整不清零已有计数。

`show` 只读，不触发旧库迁移；新版持续服务启动或显式 `set` 时增加两张普通表及索引。旧账户、资料和聊天保留。完整空间备份包含计数和设置，恢复到新目录时保留备份时的数据；恢复旧备份可能缺少其后受理记录。因此本功能不能作为服务商账单核算或跨应用、跨目录的费用硬保证。

本轮不新增外部服务或运行依赖，不自动读取真实业务数据或配置。原持续服务重启后生效，继续使用原账户和数据目录；真实 AI 回答质量仍由本人体验。
