# 成长回顾

从统一对话左侧“我的空间 → 成长回顾”进入。可查看最近7天、30天或全部已有记录，集中看到完成对话、确认教案及活跃主题，并打开近期对话、教案或主题记录。继续学习及重温沿用已有入口，不增加第二个聊天框。

回顾只读取本人成长空间的已有记录，不调用AI、不改变学习位置、不要求评分、打卡或反馈，不新增数据库表、依赖或后台定时任务。数字反映已发生的记录，不推断掌握程度、学习时长或知识增长百分比。

## 统计含义

- 最近7/30天包含今天，起点为北京时间对应日期零点，终点为本次打开时间。全部时间从现有非负时间记录开始，同样排除未来记录。
- 完成对话按实际完成时间统计，每轮一问一答计1次；失败、等待和无完成时间的记录不计入。明确保存记忆等已完成交流也属于对话记录，次数不等于AI调用、计费请求或纯学习轮次。
- 确认教案按首次确认保存时间统计；草稿与已移出草稿不计入。修订、版本恢复、收藏不重复增加数量。近期列表显示当前标题，可阅读最新版。
- 活跃主题为本期有已完成对话的现存本人学习主题，按主题编号去重。旧的未分类记录不猜测主题，也不因打开回顾自动归档。
- 汇总是本期完整数量，各列表只展示最近5项。主题记录链接保留所选主题，其他完整目录沿用各自已有的查找范围，不宣称已按回顾时间过滤。

一次读取在同一个SQLite只读事务中完成，避免汇总与近期列表来自不同写入时刻。查询按账户隔离，网页需登录、限制读取频率并禁止缓存，标题及原问题均转义后展示。空白阶段温和引导用户开始交流，不制造落后或未达标提示。

开发只使用隔离源码和虚构资料，不读取真实账户、聊天、原书或敏感配置，不调用真实AI或邮件，不停止原8785服务。
