# 已移出草稿的找回

知识资产沉淀和左侧“我的空间”提供“已移出草稿 · 找回”入口。用户可以按标题、主题和正文查找，每页最多20份；查看全文和最初参考后，主动恢复到待确认草稿目录。

恢复保留正文、标题、学习主题、原始引用和单元关联，不正式收入知识库，不改学习位置，不调用AI。仍需另行确认保存，才能重温、修订或作为已保存教案导出。移出草稿不自动清理；当前没有永久删除功能。

历史移出的草稿同样可以恢复。恢复记录与草稿同在成长空间数据库，随整库备份与恢复保留。历史数据库第一次启动只新增空记录表，无需改写已有教案。

移出和恢复只修改状态与一条恢复记录，不复制教案正文或原书文件。已移出草稿此前就保留在数据库中，本功能将其开放为可找回目录，不新增外部存储或服务费用。

每次恢复递增处理代数，使移出前打开的旧暂存、确认及移出表单始终失效；重复或并发恢复只生效一次。状态与代数在一个事务中写入，失败一起回滚。账号隔离、同源与会话绑定表单校验、限流和安全Markdown沿用现有机制。

本阶段只使用隔离源码、虚构账户和资料检验，不访问真实业务数据、SMTP或AI，不停止原8785服务。
