# 本机试用验收路线

本轮把已实现的功能放到同一学习过程里检验，重点是资料、学习位置、教案版本和来源能否一致保留。自动检验使用虚构账户与模拟Coach；真实讲解是否清楚、教案是否有帮助，仍需要实际使用判断。

## 已有账户如何开始

在原PowerShell窗口按Ctrl+C停止旧服务，再从原项目和原数据目录启动：

```powershell
Set-Location 'D:\Personal-Growth-Coach'
& 'C:\BCtools\anaconda3\python.exe' -m api.coach_run --ai --port 8785
```

打开终端给出的地址，用原邮箱和密码登录。已有账户无需重新注册或再次准备163邮箱授权码。原数据目录保持不变，别删除或改名。若原来指定过自定义`--data-dir`，继续使用原路径。

此前8821等标注虚构资料的预览页属于模拟演示空间，未连接你的个人资料。本人真实试用请进入原8785服务与原数据目录；两者账户不混用。

## 用一份熟悉的短资料走一遍

| 操作 | 重点看什么 |
| --- | --- |
| 点击对话顶端“＋ 新开对话”，发送一个不同主题的问题，再从“最近对话”打开原窗口 | 新窗口聊天区保持干净；旧窗口的记录、主题、资料与续学位置仍能恢复；新窗口不把旧聊天内容带给 AI |
| 从对话输入框的“＋ 添加资料”进入添加页，上传一份 Markdown 或粘贴短文，再直接提问 | 保存后自动回到聊天，输入区显示已上传的资料名称和当前资料状态；Coach 的回复应基于该资料片段，而不是说“没有拿到正文” |
| 打开“资料与书籍” | 页面只显示已保存资料与书籍的管理、阅读、查找和选择入口；添加资料在独立页面，不与目录混在一起 |
| 选择一个片段，回到统一对话，点击讲解或提问 | 输入框上方显示当前主题、资料和位置；“我的学习”可查看完整进度；回复引用确实来自所选内容 |
| 临时聊别的话题，再从“我的学习”点击继续学习 | 能回答插曲，也能回到原主题和原选段，不自行声称已经掌握 |
| 请求整理教案，预览、按需修改并明确保存 | 未确认前在草稿目录；保存后在已保存目录，学习状态区不堆放草稿 |
| 修改已保存教案，先预览再保存 | 预览不保存；明确保存后新增版本，旧版本仍可阅读 |
| 在版本记录中查看对比 | 标题、原文和代码变化能读懂；只是对照，未自动恢复旧版 |
| 从教案或历史问答核对引用原文 | 能看历史摘录和对应原片段；资料改名后仍能定位；缺失旧编号会如实提示 |
| 下载教案阅读版、Markdown或原资料 | 下载的是当前教案副本或原始文件；以后在线修订不会自动更新下载副本 |
| 在对话中重温教案，再结束重温 | 使用当前保存教案；结束后原主题、资料和选段还在 |
| 退出登录，停止并重启原服务，再登录 | 资料、聊天、已保存教案、版本和学习位置都仍可找回 |

上传、浏览、核对、预览、手动修订和下载不调用AI。发送、讲解、继续学习和生成教案会调用已启用的AI，沿用每日受理上限；失败不等于服务商一定没有计费。

不必填写评分表。遇到问题时，告诉开发助手“在哪一步、页面提示什么、希望得到什么”；若只是回答不够好，可直接描述哪里不好理解。不要发送密码、授权码、密钥或含验证凭证的完整邮件链接。

## 当前落地范围

目前按本机个人试用交付。已有资料导学、教案保存与修订、引用核对、手册和导出、学习记忆及本机备份；没有把这些等同于公开商用上线。

扫描PDF已支持逐页本地OCR，核对保存后供引用；无人值守整书OCR与课程生成、跨设备同步和公开部署尚未完成。后续上线前仍需明确部署环境与域名、邮件送达、备份恢复、运行成本、隐私与服务边界，并进行实际用户试用。各项已实现功能见[最新状态](project_state_snapshot.md)；真实AI操作说明见[本人试用](real-ai-local-trial.md)。
