# 书籍选段导学

从左侧“资料与书籍”打开已上传资料，可按文字片段编号定位；文字型 PDF 还可按实际文件页码定位。每页可能包含多个片段，PDF 文件页码可能不同于书内印刷页码。页面仅展示已提取的文字，不推测缺失章节；空白或不可提取文字的页会给出换页提示，不选择其他页面代替。

浏览、定位和“选中这段，回到对话”不调用 AI。选段后仍回到原来的统一聊天框，由用户点击右栏“讲解并提炼这段”，或发送自己的问题，才调用已启用的 AI。右栏靠上显示书名、实际位置及学习进度；手机速览也显示书名和选段。讲解、续学、整理教案均以选中的实际片段作为本轮资料来源，不走关键词替换；来源引用只能来自该实际片段。模型仍接收有长度限制的历史、学习记录和明确保存的记忆，讲解质量仍需真实体验。

每个片段沿用现有切分，最多约 1000 字。当前阶段用于逐段理解和提炼，不代表已经通读、总结整本书，也不自动执行全书蒸馏。选择“围绕整份资料讨论”可取消该主题的选段限制，恢复整份资料中的相关片段检索；这也不代表全书内容均被送入模型。原有 PDF、TXT、Markdown 与粘贴文字限制继续适用，本轮没有新增 OCR、EPUB、Word 或付费解析服务。

选段优先恢复当前已关联该书的主题，否则恢复最近关联该书的主题；没有对应主题时新建“研读《书名》”。同名资料会使用不同主题，避免覆盖原学习位置。每个主题分别保存书籍和选段，换段不把原有讨论进度清空；定位行为不表示已经掌握。换主题、重新登录或重启后可继续原位置，“我的学习”目录会显示实际选段。旧版没有选段的主题继续保留原行为。

选段与主题选择在同一事务内保存，正在回复时不能换段或资料；超时后的迟到回复不能覆盖新位置。统一对话表单绑定主题和选段，多个页面并用时恢复该页面明确显示的来源，不能篡改隐藏编号换用另一片段；重复消息不再调用 AI，也不通过重放改回旧选段。资料或选段不可用时提示重新选择，不悄悄以整书或其他段落替代。取消资料、改选整份资料或主动重温教案时会清除该主题旧选段，其他主题的选择保留。

教案仍沿用“生成草稿 → 用户预览确认 → 保存”的流程，不因选段或模型回复自动入库。已保存教案保留实际引用，可修订、重温和导出。学习资料 ZIP 的主题位置目录增加当前选段的真实位置；旧版没有选段表的只读导出仍可使用。本轮只增加少量选段编号和时间，不重复存储原书。

## 本机体验

重启原服务 `python -m api.coach_run --ai --port 8785`，用原账户进入“资料与书籍”，定位一个片段并选择，再在统一聊天框点击“讲解并提炼这段”。可切换其他主题后从“我的学习”继续，检查书名和选段是否恢复。无需重新注册或输入 163 授权码。只浏览和选择片段可以不启用 AI，自动开发检验使用虚构账户和模拟回复，不读取真实学习资料或连接真实 SMTP、计费 AI。

本阶段实现与检验已完成，用户确认继续下一步，按该确认保存至开发分支；真实 AI 的讲解质量仍需本人持续体验。

## 检验结果

2519 项全量回归通过（391.63 秒）；最终按钮位置、自然请求文案及选段不可用保护后，129 项相关回归通过（101.46 秒）；最终导出范围提示调整后，22 项选段与导出回归通过（6.89 秒）。Ruff 检查与格式检验通过，未新增依赖。检验覆盖精确选段引用、PDF 实际文件页码与空白页提示、书籍及主题位置独立保存、同名资料区分、重启续学、进度保留、旧页面来源绑定与防伪、重复请求幂等、账户隔离、忙碌与迟到回复保护、事务回滚、资料及选段不可用不回退、教案草稿仍待确认、重温清除旧选段，以及当前选段导出与旧数据库只读导出兼容。浏览器在虚构三页 PDF 中验证第二页无文字、第三页实际定位、选段后回到统一聊天、讲解及引用第三页、换到其他主题不带入资料、从目录继续时恢复第三页，以及生成带该选段引用的待确认教案。桌面右栏靠上显示书名、实际位置与讲解按钮，手机 320 像素页面内容宽度 305，无整页横向溢出；定位输入框、按钮均在内容区内，手机学习速览左右边为 31/274，含书名及具体页码片段。本轮开发检验只使用隔离源码、虚构账户与模拟回复，没有读取或修改真实账户、授权码、聊天或书籍，没有调用真实 SMTP 或计费 AI。保留既有 Starlette/httpx 弃用提示。真实 AI 的讲解、提炼及教案质量仍需本人体验，本阶段不表示已完成全书蒸馏。
