# 教案引用原文核对

聊天回复及完整历史问答也支持核对各自原文引用，使用同一定位规则。见 [对话引用原文核对](chat-reference.md)。

在草稿或已保存教案的“整理时参考”中点击“核对这条引用的原文”，可同时阅读当时保存的摘录和按稳定资料编号、片段编号定位的完整文字片段。页面区分历史引用书名与当前资料名，改名不会改写当时摘录；可返回教案中的同一条引用，也可明确打开该段资料预览。

核对页只读取，不选择资料、不切换主题、不确认草稿、不新增教案版本，也不调用AI。完整原文指这一文字片段，不代表整本书。原文摘录仍需用户判断是否支持当前教案，尤其是后来手动修订的内容；不把来源定位当成事实核实或掌握程度。

只读取当前账户教案以及同一账户、对应资料中的对应片段。缺少旧编号、资料不可用、编号与片段不相符或属于其他账户时，保留已存摘录并说明无法定位，不按书名、页码或文字另找替代来源。摘录与当前片段文字不完全对应时也如实提示。

原教案与引用不改写；原文按纯文字转义，不运行HTML或代码，不加载外部链接。沿用登录、只读查看限流和禁止缓存策略，不接受额外查询参数，不增加依赖、数据表、迁移、索引或后台任务。

只使用隔离源码和虚构资料检验，不访问真实账户、聊天、原书或敏感配置，不调用真实邮件或AI。
