# 资料目录整理

从“资料与书籍”进入：按资料名称或原文件名逐字筛选，英文不区分大小写；可叠加 PDF、TXT、Markdown、粘贴文字类型。筛选只影响目录，资料原文查找仍有独立入口，且可搜索全部本人资料。

每份资料提供“修改名称”，预览页也有入口。名称为1至120字，不含换行或控制字符。保存后返回原筛选目录；若新名称不再符合筛选，可点击“查看全部”。取消不写入。两个页面修改相同资料时，后保存者需核对已更新名称，再明确保存。

改名只更新本人资料的显示名称，不修改原文件名、原文、片段编号、学习目录、续学位置或已保存教案。历史问答与教案引用保留当时的名称，新预览和后续引用使用当前名称。相同内容再次上传仍指向原资料，不覆盖已改名称，不重复占容量。

容量区显示本人全部资料数量与原始内容字节数，不随筛选缩小。上限仍为20份、合计50 MB，单份10 MB。原文件与UTF-8粘贴内容计入；数据库、提取文字、对话和教案另占本机磁盘空间。容量不是整个账户磁盘占用，也不是云端套餐或费用。

无数据库迁移和新增依赖，不增加AI调用。所有读取按账户隔离，改名需登录会话、同源请求和与本份资料绑定的防伪凭证；沿用现有请求次数和请求体限制。
