# 扫描书小范围连续识别

## 使用流程

在“阅读全书”点击“识别一段页码”，填写PDF文件起止页，每批最多5页，再点击“开始识别所选范围”。这使用原书实际文件页，可能不同于印刷页或章节号。也可继续使用原来的“识别当前页”。

本机按页依次处理，已有原生文字或已核对文字的页面只显示已有内容，不重复识别或覆盖。一个批次复用同一识别组件和所选语言，逐页释放图像；不并发识别、不上传书页到外部OCR服务，也不调用AI。

识别后按页显示“待核对”“已有文字”“已保存”等状态。点击某页或上一/下一页结果，核对并修改；切换不会丢失本页修改。每次“核对无误，保存此页文字”只保存当前这一页，不代表已批准其余页面。只有已保存或原本已有正文的页面显示选段学习入口；随后仍需在原统一对话明确提问才调用AI。

## 取消、失败与数据边界

- 取消停止后续处理，已完成的待核对结果保留；尚未完成页面标为未处理。组件准备阶段取消可能需要等待资源释放，此时不能再启动另一个批次。
- 某页失败或等待超过90秒即停止本批，保留此前完成的结果，不自动重试。用户可以先保存或复制已完成内容，再明确处理未完成页。
- “放弃本批全部未保存结果”只丢弃本次尚未确认的临时文字，不改已有记录。仍有待核对文字时不能开启新批次，防止意外覆盖。
- 结果暂存在当前标签页内存；离开/刷新时由浏览器提示，不能把未保存草稿当作已入库内容。可复制留存，或核对后逐页保存。
- 沿用原逐页保存接口和登录、CSRF、PDF指纹、字数、并发重复保护。无新增后端批处理任务、数据库表或依赖；原件和旧片段身份不变。
- 清晰横排简繁体中文与英文优先。置信度只是机器提示，不保证正确；竖排、表格和模糊页面仍需核对。不是整书无人值守识别。
