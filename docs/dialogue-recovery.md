# 发送状态核对与失败消息重新编辑

网页发送等待超过60秒，或未能确定请求结果时，结束等待动效，保留当前填写并提供“核对发送状态”和刷新入口。等待超时只停止浏览器等待，不表示服务器取消了原请求。核对只查询本人本次发送编号，不重新发送、不调用AI、不增加受理次数；每次核对最多等待15秒，没有自动轮询。

已有完整回复时，核对后刷新显示已保存记录；仍在处理可稍后再次核对；已失败或超过既有180秒处理时限时提示先刷新查看。尚未查到记录不等同于确认未发送，不会据此自动补发。服务不可用时保留文字与固定提示。登录过期不再自动跳走，先提示复制文字再登录；浏览器内尚未送达服务器的文字只存在当前页面，刷新、关闭或跳转前需要本人保留。

已保存的失败消息旁增加“放回输入框修改”。仅复制原问题正文，不自动发送、不恢复旧资料选择或旧主题；提示核对当前主题和资料后再发送。输入框已有不同文字时不覆盖，正在处理其他消息或对话未启用时不可操作。上滑加载的旧失败消息采用同一行为；不将模型回复或引用作为待重发文字。新的主动发送沿用当前页面的新编号、防伪、学习位置和重温状态校验；按新请求计入受理次数，AI服务可能产生费用，不会自动重试。

状态接口按当前登录账户和发送编号查询，仅返回状态，不返回原消息、回复、资料或模型错误。编号使用既有43字符随机值，不能凭其他账户的编号查询记录；同源校验、严格单一参数、独立每来源20次/分钟及总量200次/分钟限流、禁止缓存继续生效。状态读取不改写过期记录；过期使用与现有发送一致的时限判定，后续刷新或发送仍走原过期处理与迟到回复保护。不改变AI收费或发送幂等规则。

没有新增数据库表、依赖或后台队列。文字不写入浏览器持久存储。未启用JavaScript时仍可手动复制已保存原消息，状态核对与一键编辑需启用JavaScript。常规检验仅使用隔离源码、虚构账户和模拟回复，不访问真实业务数据或配置，不调用真实邮件或AI，不操作原8785服务。

## 检验结果

2026-10-19，使用隔离源码和虚构数据检验：

- 27项新增发送状态与网页专项、3090项完整回归通过，完整回归JUnit耗时 773.90 秒；最终核对按钮独占一行的CSS调整后65项相关回归通过，JUnit耗时 56.61 秒，其余源码与完整回归快照一致。另行验证未启用AI时的只读核对1项通过，保留既有Starlette/httpx弃用提示1项。
- 5个Python文件Ruff检查和格式检查、JavaScript语法检查通过，提交前差异空白检查通过。未新增依赖、数据库表、浏览器持久存储或后台重试。
- 自动检验覆盖本人的未查到/处理中/完成/失败/到期状态、精确到期边界、只读不改变记录及用量、跨账户编号隔离、重启查询、完成编号幂等、异常参数、同源与会话、独立限流、固定安全错误、失败文字转义、忙碌与未启用AI时不可编辑，以及原聊天和重温回归。
- 虚构浏览器实际验证：已有草稿时找回按钮不覆盖输入；清空后可放回原消息；上滑自动加载的旧失败消息同样可以放回；修改后只有明确点击发送才新增消息。
- 以68秒模拟回复实际经过60秒浏览器等待超时，动效结束、输入保留，点击状态核对后显示服务器已保存的迟到回复。模拟已保存但HTTP确认丢失时也可通过核对显示回复。虚构数据库只各保留1次对应请求，无自动补发。
- 两个虚构标签页中主动退出会话后，原页发送停留在原页面，提示先复制输入再登录；未新增服务器消息，重新登录后原回复仍保留。仅重新启动自己的虚构预览，不操作原8785服务。
- 320像素手机实际找回、编辑与主动发送通过；可视与内容宽度均305像素，无横向溢出，临时窗口尺寸已恢复。最终桌面状态核对、手机重新编辑和登录过期提示截图已复核。虚构消息从45条在找回后保持45条，主动发送后46条，另一次确认丢失演示后47条；登录失效的文字未写入服务器。
- 未读取真实账户、聊天、书籍或敏感配置，未调用真实邮件或AI。未送达服务器的输入只保留在当前页面，需要在刷新、关闭或登录前自行复制；模拟检验不代表真实模型回答质量。
