# 书籍学习目录与连续导学

## 使用效果

在“资料与书籍”中打开“学习目录”，可以直接逐段学习，也可以按原书章节或个人目标添加学习单元。PDF 按文件实际页码，其他文字资料按片段编号定义范围；单元可改名、调整范围，按起点排列，不能重叠，每份最多 60 个。没有依据书籍少量片段猜测章节或全书内容。

选定位置后仍使用统一聊天框。右侧显示书籍、原文位置、当前单元和已讲解段数，可讲解当前段、直接讲解下一段；到本单元末段时提示回目录选择其他范围。没有分组时按可读原文顺序接续。原文片段有少量重叠以保留上下文，段数不代表互不重复的知识点数量。

目录编辑、浏览和选段不调用 AI。每次明确点击讲解只发起当前目标段的一次请求，没有自动处理全书的任务。原有继续上次学习保持当前位置；不把恢复位置当作下一段。原有主题、资料、选段和教案功能均保留。

## 进度与知识资产

只有主动点击选段讲解，且成功完成带该选段实际引用的回复，才保存“已讲解”记录。它是回复记录，不证明内容正确或已经掌握。聊天、浏览、选段、生成教案、失败或超时、无选段引用的回复均不新增记录；相同片段重复讲解只计一段。记录归属于用户与原始资料，多个主题讨论同一本资料共用该书讲解记录，当前位置仍归各主题保存。

修改单元范围后，以新范围计算已有记录，保留历史讲解。PDF 无可提取文字的页面不算可讲解片段，范围完全无文字时拒绝建立；页面提示进度仅覆盖可读文字，不声称处理完整全书。已有版本不追溯推断此前是否完成讲解，新增记录从本功能启用后开始。

教案仍先为草稿，经明确确认才入库；已保存教案的修订、重温、版本和导出不变。“聊天记录与学习位置”的个人导出同时包含书籍学习单元、可读片段讲解记录与上次位置，不受聊天时间筛选影响。导出不调用 AI，也不会重复附带原书正文。

## 实现与检验边界

新增两张小表存放单元和讲解记录，沿用既有 SQLite 仓储和回复事务，无新依赖、后台任务或自动计费。过期编辑保留输入并要求核对后再次保存；回复期间阻止目录修改，记录与回复同事务完成，失败回滚。目录与资料引用按账户隔离，表单绑定单元、版本、目标片段和登录会话。

本阶段实现与检验已完成，用户确认继续下一步，按该确认保存至开发分支；真实 AI 的讲解质量、自然使用效果仍需本人持续体验。

## 检验结果

2542 项全量回归通过（368.69 秒），此前 69 项目录、连续导学、选段与导出相关检验通过（38.19 秒）。Ruff 检查与 8 个 Python 文件的格式检验通过，无新增依赖。覆盖讲解记录只随成功且有实际选段引用的主动讲解写入、聊天和无引用回复不计数、重复请求不重复计数、失败与过期不计数、事务回滚、目录编辑冲突与保留输入、重叠范围并发保护、回复期间修改保护、实际 PDF 页码与空白范围、单元末尾不跳章、书籍及账户隔离、旧页面明确目标绑定、重启仓储后恢复位置与讲解记录，以及目录单独存在时的导出、聊天时间筛选不影响书籍记录和旧表兼容回归。浏览器用虚构账户建立两个单元，走通当前段和下一段讲解，首单元显示 2/2、第二单元仍为 0/2，末段显示回目录提示；展开记录可定位原文。修改首单元为片段 2–2 后显示 1/1，恢复 1–2 后仍为 2/2，原记录没有丢失。桌面及 320 像素手机页面已检验；手机页面内容宽 305 像素，目录卡片左右边为 18/287，名称与起止输入框为 37/268，聊天续学按钮为 38/267，无整页横向溢出，学习速览保留主题、书籍与片段位置。开发检验只使用隔离源码、虚构账户及模拟回复，没有访问真实账户、授权码、聊天或原书，没有调用真实 SMTP 或计费 AI。保留既有 Starlette/httpx 弃用提示。真实 AI 的讲解质量仍需本人持续体验；这一步提供学习组织与逐段接续，不表示完成全书知识蒸馏。
