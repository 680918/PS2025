# 日常使用与固定入口

本指南是当前本机持续数据空间的使用说明。尚未公开部署，不开放任意他人注册。

## 已有账户，每次这样进入

打开自己的 PowerShell：

```powershell
Set-Location 'D:\Personal-Growth-Coach'
& 'C:\BCtools\anaconda3\python.exe' -m api.coach_run --ai
```

保持窗口运行，浏览器打开 <http://127.0.0.1:8785/web/login>。用原邮箱、密码登录，不需要每天重新注册或输入邮箱授权码。可收藏登录地址。AI 配置保留在自己的本机；不要发送给开发助手。`python` 如已指向相同环境，也可直接使用 `python -m api.coach_run --ai`。

停止时在该窗口按 Ctrl+C。停止不清空记录；下次使用同一命令、同一项目和同一数据目录。若以前指定过 `--data-dir`，仍需保留原参数，否则会进入另一个空间。

不准备调用 AI 时，去掉 `--ai` 即可查阅已有内容。进入网页、阅读原书、手动修订及导出不调用 AI。

## 首次注册、找回密码或需要邮件

改用 `python -m api.coach_run --register --ai`。在自己的终端隐藏输入本人 163 邮箱授权码，网页主动操作才发邮件。凭证仅留在该次进程内；重启需要重新提供，已有验证账户只登录不需要它。目前仅允许本次配置的本人邮箱，不代表开放公众注册。

启动前只检查可执行 `python -m api.coach_run --check --ai`；不发邮件、不调用 AI、不创建账户。依赖或配置不满足时按提示处理。检查端口占用时，先确认是否已有日常服务；不要为每次使用不断更换地址。若确实需要同时运行独立测试，再明确指定其他 `--port` 与独立 `--data-dir`。

## 分清三个环境

| 环境 | 默认地址 | 记录与用途 |
| --- | --- | --- |
| 本机日常使用 | `http://127.0.0.1:8785/web/login` | `data/coach-local`，已有个人账户、书籍和教案 |
| 模拟体验 | `http://127.0.0.1:8784/web/login` | `data/coach-simulated`，模拟邮件与 AI，不产生这些服务费用 |
| 开发预览 | 以开发助手给出的地址为准，如 8826 | 检查修改，可能使用隔离虚构资料；不作为日常账户入口 |

模拟命令为 `python -m api.coach_run --simulate`。模拟和日常的数据目录分开，应用拒绝混用目录模式。端口与数据空间是两回事：仅改端口不会迁移或删除记录；换数据目录才会进入独立账户空间。同一浏览器在同一主机的不同端口可能共享 Cookie，切换环境后可能需要重新登录，不能据此认为账户已丢失。

本次将未明确指定端口的日常默认值从 8784 改为 8785；模拟仍是 8784。原先明确写了 `--port 8785` 的命令不受影响。原先日常用默认 8784 的用户改用 8785，原 `data/coach-local` 不变。自定义端口仍可用，终端显示的地址为准。

每页底部均有“使用帮助与当前环境”，显示该应用明确设置的模式、AI/邮件是否启用和版本；不根据端口猜测模式，不展示密钥、邮箱授权码或本机路径。帮助页还提供网页打不开、登录失败、发送后未回复和扫描书正文不足时的安全排查顺序；不上传诊断信息，也不自动重试。直接由开发工厂创建的页面标为开发预览；旧 `api.run` 标为旧开发入口。

## 一次完整使用

1. 登录后，在同一对话框聊天、主题学习或围绕书籍讨论。
2. 在“资料与书籍”上传或粘贴，点“阅读全书”读原文。PDF 可翻页、滚动、页码定位，阅读区域按 Enter 下一页；输入框内 Enter 保留输入用途。
3. 资料文字提取不足时，可读原始扫描页；明确识别、核对并保存文字后，Coach 才能按相应正文引用讲解。
4. 暂时换话题后，从右侧继续原学习位置。整理的教案先预览，明确确认才保存，统一在左侧知识资产目录管理。
5. 定期导出学习资产并做整库备份。导出便于阅读携带；整库备份用于恢复账户与完整空间，两者不能互相替代。详见[本机备份说明](local-backup.md)。

登录失败时先检查地址、数据目录、邮箱验证与密码；不要删除数据或重新注册来“修复”。需要人工排查时只提供操作和提示，不发秘密信息。完整验收路线见[本机试用验收](local-trial-acceptance.md)。
