# 统一对话阅读与知识资产入口调整

依据本人真实 AI 试用反馈调整，继续保留一个聊天输入框。

- 回复和教案使用同一安全 Markdown 排版：标题、加粗、列表、表格与代码；较宽表格、代码在专用区域横向滚动，保留代码缩进。原始 HTML 只作文字显示，不加载模型给出的图片或链接，不执行代码。历史分页使用同一服务端渲染器。
- 发送、续学、整理教案提交后显示三个跳动圆点和等待文字；本机设置减少动态效果时保留静态标识。页面在原地等待单次请求完成，然后读取新回复；沿用现有表单字段、CSRF 与一次提交一次处理机制，不增加请求重试。网络结果不明确时提示先刷新记录，避免重复发送。未启用脚本时保留原生表单提交。
- 每次打开或返回对话，从最新回复开头定位，长回复不再直接跳到末尾。上滑加载旧记录时继续保持原阅读位置。
- 欢迎信息放在左侧导航，三栏在页头下方顶端对齐；输入区缩为两行，扩大聊天阅读区。手机保留主题摘要、资产入口和独立聊天滚动区。
- “知识资产沉淀”集中在左侧：教案草稿的预览、修改与确认保存，以及已保存教案目录的查找、调阅、重温与导出。整理操作也置于此处。右侧仅保留学习主题、讨论进度、下一步、实际资料引用与续学，不再堆叠教案草稿卡片。
- 点击继续学习后，新回复以“我们回到「具体主题」学习主题上来。”自然承接，不使用“先把位置对齐”。已经保存的原始对话不批量改写，只更新显示排版；新续学开头从本次起生效。

本步不改变账户、原始对话、资料和教案的存储结构，不需要迁移或重新注册。草稿仍需本人明确点击确认保存，不自动入库。自动检验与页面预览使用虚构账户和模拟 AI，真实服务需用户在自己的终端停止后按原命令重启以加载代码；重启不删除持久数据。

## 检验结果

2338 项全量回归通过（249.79 秒），最终模拟措辞和前端修正另有 43 项相关检验通过；Ruff 检查与格式检验、JavaScript 语法检查通过。浏览器实际检验桌面三栏顶部均为 158 像素，阅读区 560 像素、输入框约 50 像素，长回复第一行位于阅读区顶部约 8 像素；等待中有 3 个动态圆点，完成后恢复发送并从回复开头阅读。上滑已加载全部 49 轮模拟记录且旧回复表格代码同样排版；草稿预览、明确保存、目录调阅、同一对话重温和生成新草稿已走通，右栏没有草稿卡片。320 像素手机检验无整页横向溢出，表格与代码各自滚动，代码缩进保留。所有检验使用虚构账户，不调用真实 SMTP 或计费 AI。
