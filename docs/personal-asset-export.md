# 个人学习资产导出

已保存教案还可以直接下载独立HTML阅读版，保留当前版本、表格代码、原引用与生成范围；副本不会随在线修订更新。详见 [单份教案离线阅读版](lesson-readable.md)。

保留“用户确认后保存到 Coach”，新增左侧“导出我的学习资料”。导出是用户主动下载阅读副本，不替换 Coach 中的保存，不删除原内容，也不调用模型或邮件服务。

页面显示本人当前内容数量，默认勾选已保存教案。用户可再选待确认草稿、聊天记录与当前学习位置、上传或粘贴的原始资料。聊天可选全部、最近 30 天、最近 90 天；只影响聊天消息，不影响教案、资料或当前学习位置。没有内容的类别不可选。

ZIP 包内提供“打开这里.html”分组目录与使用说明；完整解压后可直接用浏览器阅读目录和教案。已保存与待确认教案分开存放，分别包含安全 HTML 阅读版、Markdown 文本和已有引用说明。聊天提供 HTML、TXT，包含用户消息、教练回复、引用和未完成状态；当前学习位置单独保留。原始 PDF、TXT、Markdown 按原始字节导出，并用编号和安全文件名避免重名、路径越界和 Windows 文件名冲突。

导出使用服务端登录身份，无用户编号参数；校验来源、会话绑定防伪凭证、字段及时间选项。只读取本人记录中的明确字段，不导出账户表、密码哈希、会话令牌、消息提交凭证、邮箱凭证或 AI 配置。HTML 使用禁用原始 HTML、图片和链接的 Markdown 渲染，引用以转义文字显示；阅读页只含受控本地目录链接和固定样式，不执行代码或访问外部资源。原始资料和 Markdown 文本保持其内容，用户应按自己的文件保管习惯保存。

只读事务分别读取对话和资料数据库，构建后释放读取连接；不是跨数据库的原子备份，也不提供整库恢复或账户迁移。每包未压缩内容最多 512 MB、最多 5000 个文件；超过时明确失败，不静默截断。可按类型拆分、缩短聊天时间范围后重试。

临时压缩包内存缓冲上限 1 MB，较大时使用系统临时文件；下载按块发送，完成或关闭迭代器时清理。最多 2 个正在准备或下载的包；每账户每分钟最多 2 次，应用总计每分钟 10 次，另受现有页面操作限流。服务器不长期保存重复 ZIP。前端显示准备、接收与交给浏览器下载的状态，不擅自宣称文件已落到用户硬盘，不自动重试；无脚本时保留原生表单下载。

自动检验及页面检验使用虚构账户、资料和模拟 AI。本人真实数据由本人在页面自行选择后下载；开发过程不读取或导出真实学习内容。

## 检验结果

2358 项全量回归通过（321.19 秒）；最终容量提示与离线返回链接检查后，20 项导出相关检验通过（8.85 秒）。Ruff 检查与格式检验、JavaScript 语法检查通过。浏览器实际下载两份虚构资料包：默认仅含已保存教案的 4 个文件，勾选全部类型并选择近 30 天后含 10 个文件；已安全解压并核对目录与阅读页相对链接，原始字节及草稿状态的保留由自动检验确认。浏览器检验默认只有已保存教案勾选，空选择提示有效；320 像素新标签检验无横向溢出，按钮位于卡片内。浏览器工具禁止 file 协议，未绕过该限制；离线 HTML 的实际视觉阅读留待本人下载后确认，目录、HTML 结构与链接已检验。所有检验均使用虚构账户，未调用真实 AI 或邮件。

## 本阶段保存

用户已确认继续下一步，按该确认保存本阶段实现与检验记录。离线 HTML 的实际视觉阅读仍待本人确认，不将继续开发等同于已完成该项体验。

## 学习记忆

长期学习记忆上线后，导出页面新增可选“学习记忆”，提供安全 HTML 阅读版和 TXT 原话副本；默认仍仅勾选已保存教案。记忆与聊天时间范围无关，按本人当前保存内容导出，内容和状态不变。

## 多主题学习位置

勾选“聊天记录与学习位置”时，除原聊天和当前学习位置外，包含本人全部学习主题当前的进度、下一步和关联资料名称，提供 HTML 与 TXT 目录。聊天时间范围只过滤消息，不过滤主题位置；只读旧版数据库时不会为导出创建主题表。

教案持续修订后，单篇下载和打包导出均使用当前标题、正文，引用继续保留为最初整理时参考。本轮导出仅含当前内容，历史版本可在 Coach 的“版本记录”中阅读和恢复；不改变原版和修订记录。详见 [教案修订](lesson-revision.md)。

主题学习位置目录增加当前选段的实际位置，便于留存书籍导学进度。仅导出登录账户可读资料的实际定位信息，不增加未经确认的知识成果；旧版没有选段表的只读数据库仍可导出。

## 书籍学习目录与讲解记录

选择“聊天记录与学习位置”时，也导出当前用户的书籍学习单元、上次选段与逐段讲解记录，不受聊天时间筛选影响；进度只涵盖可提取文字，已讲解不代表已掌握。不重复附带原书正文，兼容没有这项新表的旧数据库只读导出。

## 单元教案范围

单元教案的单篇 Markdown 和打包导出阅读版、Markdown，保留生成时书籍、单元、范围、已讲解比例及批次说明；用户修改正文或调整目录不会改写范围记录。旧教案与旧数据库的只读导出继续兼容。

## 整册学习手册

手册阅读版与 Markdown 保留导出时的续读章节说明；按教案编号解析当前位置，已经移出或暂不可用时给出提示，不泄露其他账户教案。阅读位置不等于已完成或掌握，不改变聊天与主题进度。兼容没有位置表的旧数据库，离线副本不会回写线上位置。

个人 ZIP 新增独立“学习手册”选项，按目录收录导出时的教案版本、引用和单元整理范围，包含 HTML 阅读版和 Markdown。也可从手册页面单独下载整册；不受聊天时间筛选影响。导出副本不会自动跟随 Coach 中的后续修订，原教案与目录继续保留。旧数据库无手册表时仍可导出现有类型。
