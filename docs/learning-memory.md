# 长期学习记忆第一版

在统一对话中单独发送“请记住，我喜欢先看例子再看概念。”或“请记住：我的学习目标是通过小项目入门 Python。”，系统按用户原话保存，不调用 AI，也不要求每轮填写反馈。明确请求后的内容按一条记忆保留，不由模型推断用户背景、掌握程度或性格。

只有消息开头的明确“请记住／请你记住／请帮我记住／帮我记住”请求会进入此流程。普通对话、带引号的示例、书籍片段和模型输出不会自动新增记忆。每条 1–300 字，每账户最多 20 条；重复内容不重复增加，到达上限给出未保存提示，不自动覆盖或截断。部分常见的密码、授权码、验证码和密钥赋值会被拒绝，这不代表能识别所有敏感信息，也不代表从聊天中清除了这些内容。

左侧“我的学习记忆”可查看、手动添加、修改和明确确认后删除。普通页面操作不调用 AI。用户可以在没有开启 AI 的情况下管理既有记忆；从聊天新增仍需进入已启用的统一对话入口。修改和删除使用记录版本，旧页面不能悄悄覆盖新内容或删除已修改记录；冲突时展示当前内容并保留尚未保存的填写内容，供用户核对。

记忆按登录账户保存在现有 `coach_conversations.db` 的新增表中，重启后保留，不新建账户，不迁移或重建原有资料。对话中的记忆保存与成功回执在同一数据库事务完成，重复请求不反复保存，超时的旧请求不能补写。新增表是向后兼容建表，原对话、学习位置、教案和引用记录保持原关联。

后续发送、续学或整理教案时，系统在有长度上限的最近对话之外另提供该账户全部已保存学习记忆；最多 6000 字的内容，不含记忆编号或其他账户信息。它们是用户自述数据，不是系统规则，不代表已验证的掌握程度，当前问题仍优先。对话中明确保存记忆的轮次保留供网页阅读，但不再进入模型最近对话，以免删除或改写后从旧的保存命令重新引入旧记忆。普通历史聊天中仍可能存在相同信息，删除记忆不会删除历史对话、已生成回复或撤回已经发给 AI 的内容；正在生成的回复也可能已经拿到旧上下文。删除从之后的新请求生效。

新记忆随正常问题提供给已配置的 AI 服务，会增加输入长度；不额外发起“记忆提取”模型请求。真实 AI 是否能自然、恰当地利用目标和偏好仍需本人体验。现阶段没有自动画像、自动归纳、向量检索或跨设备同步。

“导出学习资料”增加可选的“学习记忆”，默认仍仅选已保存教案。记忆提供安全 HTML 阅读版和 TXT 原话副本，沿用现有临时 ZIP、账户隔离、容量与下载清理机制；不提供整库恢复。导出文本由用户自行保管。

所有新增页面校验服务端登录账户、来源、会话及用途绑定防伪凭证；请求体有长度和字段限制，读写有限流。保存或查看时只读当前账户内容，用户编号不作为请求参数。页面只按纯文字转义展示记忆，不执行其中的 HTML 或代码。

## 本机体验

用原来的账户登录，在统一对话输入一条“请记住……”；打开左侧“我的学习记忆”核对，修改偏好后再聊一个问题，退出重进后仍可查看。删除需要在页面明确确认。普通启动用原来的 `--ai` 即可，记忆功能不需要再次准备邮箱授权码。

开发检验仅使用隔离源码副本和虚构数据，不读取本人账户、授权码、聊天或资料，不发送真实邮件，不调用计费 AI。本阶段已完成实现和检验，用户确认继续下一步，按该确认保存开发分支；真实 AI 的个性化交流质量仍需本人持续体验。

## 检验结果

2430 项全量回归通过（327.33 秒）；最终内置浏览器表单兼容修正及保存回执文案调整后，112 项相关回归通过（70.43 秒）。Ruff 检查与格式检验通过。检验覆盖明确保存而不调用 AI、普通聊天和引用不误存、账户隔离、重启持久保留、历史范围外的记忆注入、删除后不从保存命令历史重新引入、模型输出不能写入、重复与容量并发、事务回滚、旧版本编辑删除冲突、来源和防伪校验、五类导出及旧数据库只读导出兼容。浏览器使用虚构账户走通对话保存、集中查看、修改和手动添加、后续模拟回复参考新偏好；查看删除确认并取消，实际删除由隔离自动检验完成。实际下载的学习记忆 ZIP 含预期 4 个文件，已核对两条最新原话与本地返回链接。桌面与 320 像素手机布局已检查，手机内容宽度 305 像素、卡片和输入框无横向溢出。实际浏览器发现 Origin 为 null、Sec-Fetch-Site 为 same-origin 的表单场景；修正仅在该同源元数据且防伪凭证正确时允许，跨站或伪造防伪仍拒绝，已补回归。没有读取或改写真实账户、授权码、聊天和资料，没有调用真实 SMTP 或 AI。真实 AI 自然运用学习目标与偏好的质量仍留待本人体验。
