# 按日期找回对话

在“对话记录”填写可选的开始和结束日期，可与关键词、学习主题一起筛选。按发起对话的北京时间计算，包含开始日零点及结束日整天；只填一端代表另一端不限，日期都留空仍是原来的全部记录。结束时点以次日零点之前为准，不按服务器时区或浏览器时区猜测。

翻页、打开完整问答、相邻问答及返回目录会保留原关键词、主题、日期和页码。“清除日期限制”保留关键词和主题并回到第一页。相邻问答仍按原主题连接，若超出日期范围会明确提示；不会隐藏可阅读的本人问答，也不切换当前学习位置。单轮下载保持原入口，导出这轮问答自身的内容，不附带搜索条件。

日期为真实日历中的年-月-日，拒绝错误日期、重复条件和开始晚于结束。只查当前登录账户，参数化SQL沿用现有分页与查看限流；匹配和输入转义、禁止缓存等保护保持。查询参数可能进入本机浏览器历史。

不调用AI，不改写对话、续读、主题或知识资产，不新增依赖、表或数据库迁移。检验只用隔离源码与虚构账户、日期和对话，不读取真实数据或敏感配置，不调用真实邮件或AI，不操作原8785服务。
