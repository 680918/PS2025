# 本机账户完整试用

本轮提供独立的账户应用，支持注册、验证、邮箱密码登录、私有欢迎页和退出。登录后的首页已按用户反馈统一为一个对话工作区，聊天、主题学习和书籍讨论共用同一输入区，另设知识库与资料管理标识；这些功能暂处准备状态。旧开发入口使用用户编号，未挂到该应用中，避免在身份绑定完成前访问旧资料。

## 模拟体验

在项目目录的 PowerShell 中执行：

```powershell
python -m api.account_test --simulate
```

打开终端给出的注册页，用虚构邮箱和一段至少 15 字的临时口令保存申请，点击模拟发送；打开终端给出的模拟收件箱，确认邮件后进入登录页。登录后可查看欢迎页并退出。本机模拟收件箱仅在模拟模式存在，并校验当前申请的浏览器归属。

## 向本人 163 邮箱做真实验收

```powershell
python -m api.account_test
```

按终端提示输入本人 163 邮箱和客户端授权码（隐藏输入），输入“开始”确认开启。随后在网页注册同一邮箱，设置产品登录密码，点击发送；在真实收件箱打开邮件确认，再登录、退出。客户端授权码只用于发件，不是产品密码，也不要发到聊天中。工具仅允许向已在终端确认的同一邮箱投递，打开网页不会自动发信。

完成退出后，在终端按 Ctrl+C。工具核对同一临时账户是否完成邮箱验证、登录与主动退出，并显示结果。临时数据库随服务退出清理；现有 `.env`、账户和学习资料不改动。端口冲突可加 `--port 8783`；只能监听本机，没有公开部署选项。

## 登录与数据边界

- 只有已验证邮箱且具备密码的账户可登录。未知邮箱、错误密码、未验证和旧账户无密码均给出相同提示；密码不回填。
- 使用 Argon2id 校验，未知邮箱也执行虚拟校验。每应用最多同时校验 2 份，登录提交每来源每分钟 5 次、进程总量 50 次；来源不信任任意转发头。
- 登录成功生成随机会话，数据库只保存摘要。Cookie 为 HttpOnly、SameSite=Strict、路径 `/web`，HTTPS 下启用 Secure。最长 8 小时，不因刷新续期。
- 登录表单有同源检查、短期签名 Cookie 和防伪字段；退出只接受带会话绑定防伪字段的 POST，服务端撤销后旧 Cookie 重放无效。
- 欢迎页只从当前会话读取本人资料，不接受 URL 或表单中的用户编号。所有私有页面禁用缓存和引用来源；姓名等字段经过转义。
- 新账户应用不导入 AI 配置，不加载 `.env`，不暴露旧按用户编号操作的接口、API 文档或学习页面。`python -m api.run` 仍是旧本机开发入口，本轮账户试用请使用上面的独立命令；旧入口不能公开部署。
