# 教案草稿暂存

在“知识资产沉淀 → 教案草稿”打开草稿，展开“修改草稿标题和正文”。点击“暂存草稿，稍后继续”会保存本次标题、正文，仍留在草稿目录；下次打开或重新登录、重启后可以继续整理。只有明确点击“确认保存到知识库”才变成已保存教案，可重温、修订、成册与导出。

暂存为手动操作，不是自动保存。未点击暂存或确认的填写不会保留。草稿只保留当前修改内容；已保存教案的版本记录仍从确认后的内容开始。普通修改、暂存、确认均不调用AI、不新增AI受理次数。段落换行兼容浏览器表单格式。

保留原主题、对话归属、原书引用、学习单元范围和创建时间，暂存不修改学习进度。草稿查找和用户明确勾选的草稿导出读取当前暂存内容；默认已保存教案导出不包含草稿。未确认的草稿不能重温或收录手册。

暂存、确认和移出草稿目录均核对本页看到的草稿版本；旧页不能覆盖新暂存内容、确认过期内容或隐藏新草稿。发生冲突时显示当前内容入口并保留本次填写，需核对后再次明确操作。若已被另一页确认或处理，仅提供本次填写的复制区域，不把它改回草稿或覆盖已保存教案。

沿用现有账户、同源、防伪、请求限制和SQLite事务；无需数据库迁移、新依赖、后台任务或额外AI调用。原内部确认接口保持兼容，账户网页统一使用带版本核对的草稿写入流程。
