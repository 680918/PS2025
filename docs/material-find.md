# 资料原文查找与定位

“资料与书籍”顶部提供“查找资料原文”，可在全部本人资料或指定书籍中按关键词查找。每份资料的原文预览也提供查找框，默认范围为当前书籍。查找结果按书籍上传时间、资料编号和片段顺序稳定排列，每页最多 20 个匹配片段。

每条结果包含书名、实际 PDF 文件页码或文字片段编号，以及首处匹配附近的原文。点击“查看原文并选段学习”打开该片段，显示附近原文和完整文字，匹配文字高亮。可返回原来的关键词、查找范围与结果页码；查看相邻片段和按页码定位时保留这些返回条件。

查找、翻页和预览不调用 AI，不改变已选择的资料、主题、书籍位置或已讲解记录。“选中这段，回到对话”沿用既有受保护操作；之后点击讲解或发送问题，才会把该片段交给启用的 AI。教案继续由用户明确确认保存。

## 范围与限制

- 只查找当前登录账户已上传或粘贴、成功提取的资料原文；不查聊天、教案、其他用户资料，也不下载外部内容。教案正文使用“知识资产沉淀”的查找。
- 按输入文字逐字匹配，英文 ASCII 字母不分大小写；`%`、`_`、引号按普通文字处理，不作为通配符。每次最多 120 字，空查找仅显示操作提示。
- 一条结果代表一个文字片段，不代表一本书或独立知识点，也不表示掌握。原有相邻片段存在重叠，因此同一段原文可能出现在相邻结果中。
- PDF 文件实际页码可能不同于书内印刷页码。仅查已提取文字；断行、提取顺序和编码会影响匹配，可尝试更短关键词。扫描图片、无文字页无法查找。不做 OCR、语义搜索或全书 AI 摘要。
- 从结果进入预览时，首处上下文最多包含关键词前后各 70 字，并按原文行截取；完整片段仍可阅读。所有原文和查询文字转义后显示，HTML 或代码不执行。
- 查找结果与原文页使用已有登录校验、查看限流、禁止缓存和不传递来源的响应头。关键词位于本机页面 URL，可能保存在浏览器历史中。

无需新增依赖、索引服务或数据库迁移。查询使用当前片段表，最多返回 20 条结果和一条下一页标志，不读取原始文件 BLOB，也不把整书放入页面。
