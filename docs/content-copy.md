# 回复与代码复制

统一聊天中的已保存回复、向上加载的旧回复，以及“对话记录”的完整问答详情，增加“复制回复”和“复制代码”。回复复制页面可读正文，包含段落、表格文字和代码；不包含复制按钮、状态提示或折叠引用。引用仍可单独阅读，完整问答及引用可沿用下载入口。

代码复制只取代码正文，保留换行与空格缩进，不包含代码语言标签。围栏代码和缩进代码均可使用。按钮可用键盘操作，以状态文字明确成功、空内容或未获浏览器许可；失败时可选中文字手动复制，不尝试读取剪贴板或调用过时的浏览器权限绕过方式。

脚本只在统一聊天与完整历史问答页面加载；内容沿用已转义的消息与安全Markdown，复制只写入本机剪贴板，不向服务器或外部发送正文，不读取剪贴板、不调用AI、不保存新数据。离线导出和其他页面的正文不变。历史加载在计算滚动高度前同步加入按钮，保留正在阅读的位置；新回复沿用已有页面刷新。

未新增依赖、数据库表、持久浏览器存储或后台任务。检验使用隔离源码与虚构数据，不读取真实账户、聊天、书籍或敏感配置，不调用真实邮件和AI，不操作原8785服务。
