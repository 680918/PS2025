# 从阅读页建立学习单元

在 PDF 原书阅读器中，当前文件页有可引用文字时，可以点击“把当前页设为学习单元”。本地 OCR 的结果核对并保存后，也会出现相同入口。它打开的是预填的学习单元编辑页：范围默认为该文件页，名称默认为“第 N 页”。用户仍可修改名称和范围，必须再点击“保存学习单元”才会写入目录。

尚无文字的扫描页不会创建空单元。入口会回到相同文件页的 OCR 核对区，用户可以自行识别、修改和保存；不会自动开始 OCR、不会自动创建目录、不会调用 AI。已有文字的单页预填、打开编辑器及取消返回都是只读操作，不改变阅读书签、选段学习位置、讲解记录或知识资产。

学习单元仍使用实际 PDF 文件页码，和印刷页码可能不同。范围必须包含可引用文字，编辑器也继续检查本人账户、页码、重复参数、单元重叠和保存冲突。单页设置成学习单元不表示已经讲解或掌握；回到统一对话后，用户再明确点击讲解，才会产生一次带原文引用的学习记录。用户可在目录中把若干相邻页整理为自己的章节或学习目标。

## 检验

2026-10-22，隔离源码的17个阅读、OCR、页码总览、选段学习、学习目录与单元教案测试文件共209项通过，0失败、0错误、0跳过（JUnit 200.46秒）；其中本轮新增12项端到端、参数边界和前端链接同步检查。4个Python文件通过Ruff静态检查和格式检查，2个JavaScript模块通过语法检查。保留既有TestClient的1项弃用提示。

- 测试确认：扫描页尚无文字时，入口只重定向到同页OCR核对区；确认保存后，入口只重定向到预填编辑页；打开编辑页前后资料库与对话库字节不变，0次Coach调用。空值、越界、重复参数和附加参数都会拒绝，不能借入口绕过页码或账户校验。
- 预填编辑器实际复用既有单元保存、防重叠、冲突和原文范围校验。自动检查覆盖OCR逐页与批量保存、原页对照、正文页码总览、书签、目录、逐段讲解、单元教案整理，以及账户隔离。
- 浏览器只使用已有的虚构扫描书：直接打开第12页的入口后，实际进入“添加学习单元”，名称为“第12页”，起止PDF文件页码均为12；未点击保存。预览不调用真实AI、邮件或网络请求，未操作原8785服务和个人资料库。

本轮不是全项目回归、手机实机验收或真实AI讲解质量验收。日常本机服务按既有方式重启后，使用该产品的人可以从阅读器或OCR结果进入这个预填步骤。
