# 正文页码总览

在“资料与书籍”、文字预览或“阅读全书”打开“正文页码总览”，按PDF文件实际页码查看三种状态：已提取文字、OCR已核对保存、尚无文字。每页只出现一次，不按片段数重复计数；可筛选状态，每次最多显示50个文件页。

“已有文字”表示这一页有可供Coach引用的片段，不保证整页提取完整或排版正确，也不代表已经讲解或掌握。“尚无文字”也可能是空白或插图页，需先看原页；未确认的OCR草稿仍只在原标签页内存，不计为已保存文字。

总览提供第一处尚无文字的页，以及从该页起最多5页的准备入口。点击后打开相同文件页和原核对区，页码表单默认从该页开始；不会自动识别。仍需明确点击识别、核对并逐页保存，已有文字自动跳过。每行也可直接阅读原页，已有文字可直接打开对应文字预览。浏览总览不改变位置；明确打开原书后，仍按原阅读器正常记录阅读页，不改变选段学习位置。离开存在未保存草稿的阅读页时，仍由原浏览器离开提示保护。

只在服务端读取本账户的页码元数据，不提取整书正文、不重解析PDF、不调用OCR、AI或邮件，不改变阅读书签、学习位置或知识资产。保存后刷新总览反映最新结果。原页状态不存入新的缓存或表，普通重启或既有整库恢复后从原记录读取。无新依赖或后台任务。
