# 原文翻页按钮与Enter下一页

知行阅读页的上一页、下一页使用原生GET表单：组件尚在加载或初始化失败时，仍可按实际文件页跳转。组件就绪后在当前页面切换，无需重新下载原书。首页的上一页、末页的下一页保持边界禁用，但使用正常光标及明确标题说明，不让用户误以为无权阅读。

阅读区域可聚焦，按Enter到下一页；末页显示已到最后一页，不越界。输入框、页码框、OCR核对框、选择框、按钮、链接、展开控件和可编辑文字保留原生Enter行为；组合键、输入法正在选词以及长按重复事件不会触发阅读快捷键。方向键与鼠标滚动保留原行为。滚动时按阅读参考线所属的书页确定当前位置，避免把尚未读到的下一页提前当作当前页。

浏览器原生PDF页不由知行脚本控制，知行的按钮和Enter快捷键在地址以`/read`结尾的网页阅读器使用；`/read/pdf`保留原始PDF直开作为独立备用入口。页面对此作出简短说明。阅读脚本加版本参数，避免继续使用旧缓存。

不调用AI、OCR或邮件，不改数据库结构、原件、账户和学习记录。不增加依赖或后台任务。
