# 统一对话与个人知识积累

## 已确认的产品方向

用户在完成真实 163 注册、邮件确认、登录与退出后反馈：聊天、主题学习、围绕书籍和资料的讨论，应该在同一个对话框里完成。登录后的主工作区因此采用一个持续对话入口，而不再将聊天和学习分成不同入口。

主工作区的导航为“对话”“知识库”“资料与书籍”。知识资产是知识库中可复用成果的统称，包含笔记、教案、学习册、总结等，不另设重复入口。原始书籍与资料提供讨论依据，整理形成的成果进入知识库；保留来源、主题与版本的关联，后续逐步实现。

## 用户如何使用

- 可以直接闲聊、请教问题、提出学习目标或围绕书籍提问，不必先选择聊天或学习模式。
- Agent 根据对话理解当前目标，保留正在学习的主题和进度；用户临时换话题时先满足当前需求，在合适时机自然回到原主题。
- 上传书籍与其他资料可从“资料与书籍”管理，也可从对话中的“添加资料”发起。资料是否参与本次对话，应有清晰的选择和标识。
- 用户可以在对话中要求整理教案、知识点、学习册。Agent 也可以主动提出整理建议，由用户确认后保存到知识库；不强制用户填写理解分数、难点或下一步反馈。
- 后续查询已保存成果、继续学习或引用资料，仍回到同一个对话区完成交流；知识库和资料页提供查找、管理与调用功能。

## 当前实现边界

用户进一步确认：主题学习、围绕资料的专题学习，都必须看得见“当前学习主题、学习进度、正在引用的书籍资料”，并能够快速继续上次学习。统一对话入口不能削减这些能力，学习状态是主工作区的固定组成部分。

本步将统一对话按登录账户保存，增加可选 AI 回复和持续本机入口。学习栏显示教练根据讨论生成的主题、已讨论内容和下一步；转题保留记录，按钮在同一对话中续学。页面刷新、重新登录与重启可以恢复记录，不展示虚构的掌握百分比。

资料上传、选择和片段检索现已接通，右侧显示所选资料，回答旁展示真实片段和出处。教案先以草稿呈现，用户预览和确认后才保存；Coach 也可以提出整理建议。知识库支持查找、导出和在原对话中重温。具体限制见资料与教案说明。

原有按用户编号操作的学习与知识模块不能直接对外开放。本步已将资料上传、有来源的讨论、经确认保存与重温接入统一账户空间。用户已于 2026-10-18 授权按蓝图自主推进，检验后直接提交同步，以阶段汇报和体验替代逐步确认；见 [开发方式](development-workflow.md)。当前实现与运行边界见 [持续对话说明](coach-dialogue.md)。
