# 学习手册内查找

在手册阅读页输入关键词，查找本册已收录、本人已确认保存且当前可用的教案标题、主题与正文。结果按目录顺序展示，每页最多20章，显示当前章节号、教案版本、匹配字段及一段原文片段。只做原文字词查找，英文ASCII字母不区分大小写，通配符按普通文字处理；最多120字，不支持语义扩展。

点击结果打开对应教案，阅读页保留查找关键词与结果页码，并显示当前匹配片段。结果链接绑定教案编号，目录重排后仍打开同一教案；已移出目录的结果明确提示重新查找，不改用其他章。目录、上一章和下一章继续保留返回查找的入口。修订后查找使用最新版，旧页面打开时以当前正文为准，不再匹配时如实提示。

查找不包含引用摘录、其他手册、未收录教案、草稿、移出草稿或其他账户的教案；不可用章节跳过。只返回有长度限制的匹配片段，不返回章节全文、来源标识或请求凭证。查询和目录读取位于同一数据库事务中；原有每册100章上限保持不变。

查看、查找、翻页和打开结果不会改变续读位置或学习主题，只有原来的“记住本章位置”明确操作才保存位置。无AI调用、数据库迁移、新依赖、索引服务或后台任务。关键词在本机URL中，可能进入浏览器历史；页面按现有账户与查看限流核对，禁止缓存，所有匹配文字先转义，不执行HTML或脚本。

检验仅使用隔离源码与虚构账户和教案，不读取真实数据或敏感配置，不调用真实邮件或AI，不操作原8785服务。
