# 单份资料原件取回

在“资料与书籍”的目录、原文预览或书籍学习目录点击“下载原件”，单独取回当初上传并保存的完整PDF、TXT或Markdown；粘贴内容取回为保存时的UTF-8文字文件。无需先打包整个资料库，不改变原文件、解析片段、资料选择、学习进度、聊天或教案，不调用AI。

取回的是本机保存的原始字节，包含原编码和换行；PDF保持完整原文件，不重新生成版面。资料改名后下载使用取回时的当前名称及原类型扩展名；特殊字符、保留名称和过长名称会作安全处理。取回文件名变化不会修改内容或原上传文件名，离线修改不自动同步到Coach。

仅当前登录账户可取回本人资料，凭其他账户的资料编号不能下载。下载以附件返回，禁止缓存和内容类型猜测，不把原文直接作为网页执行。原文件按现有10MB上限读取，并核对保存指纹；无法完整读取或校验失败时不给出损坏附件。只读单行查询提供一致的名称和原件快照，不新增数据库表、依赖、临时导出文件或迁移。

每账户每分钟最多6次原件下载请求，全空间每分钟60次；失败的已受理请求也计入此短期限流。原件取回与既有整包导出共用最多2个并行处理位置，完成、失败或关闭流后释放；不占用AI每日受理次数。导出整库仍使用原来的ZIP入口，单份取回不包含教案、聊天或账户恢复信息。

常规检验只使用隔离源码、虚构账户与资料，不访问真实账户、聊天、原书或敏感配置，不调用真实邮件或AI，不操作原8785服务。
