# 对话引用原文核对

聊天回复和右侧“最近回复引用”展开后提供“核对原文（新标签页）”。打开时保留原聊天页、输入文字和滚动位置；核对页可返回本轮完整问答的对应引用。上滑加载到最近40轮以外的问答，也提供相同入口。

历史“对话记录”的完整问答中，每条引用均可核对原文，并返回同一条引用；原来的关键词、主题、日期范围及结果页码继续保留。引用只读取这轮保存的快照，不以当前选中的书籍替代历史来源。

原文核对复用教案的编号定位和归属校验，区分回答时的书名、摘录与当前资料名和片段。旧引用无编号、资料不可读或片段不符时保留摘录并说明原因，不按文字或书名另找来源。定位不代表回复全部说法已经核实。原文以纯文字显示，PDF位置为提取时实际文件页码。

所有查看均不调用AI、不重新发送问题、不选择资料或切换主题，不改写对话、教案或学习进度。沿用本人登录、查看限流、禁止缓存和来源保护，无新增依赖、数据库迁移、持久浏览器存储或后台任务。

检验仅使用隔离源码和虚构账户、资料，不访问真实业务数据和敏感配置，也不调用真实AI或邮件。
