# 教案保存前的排版预览

在草稿“修改草稿标题和正文”或已保存教案的“修改教案”中填写后，点击“预览排版（不保存）”。页面使用与正式教案相同的安全Markdown排版，显示本次标题、段落、表格与代码，并明确标注尚未保存。预览只针对当前填写的标题和正文，不重新生成引用或整理范围。

“返回编辑”跳回原输入，保留本次填写。需要留存时仍明确点击“暂存草稿”“确认保存到知识库”或“保存修订”；预览本身不做这些操作，也不调用AI、不创建版本、不修改当前学习位置。普通表单即可使用，无须启用额外编辑器或安装依赖。

沿用原表单的账户、用途、防伪和基础版本核对。另一页面已更新或确认草稿时，先提示核对并保留本次填写，不通过预览悄悄覆盖或把教案改回草稿。预览后再次保存仍走既有防冲突流程。内容校验失败保留填写；频繁预览或读取异常时提供只读复制区。

预览只在登录用户自己的可编辑教案中提供，不接受附加查询或任意HTML渲染地址；请求体、标题与正文有上限，并有独立短期限流。正文原始HTML、链接和图片继续按文字处理，标题按纯文字转义。浏览器可能在刷新POST预览页时询问是否重新提交；再次提交仍只是预览，不会保存。

没有新增数据表、迁移、浏览器持久存储、后台任务或模型调用。仅使用隔离源码、虚构账户及教案进行检验，不访问本人真实学习内容或敏感配置。
