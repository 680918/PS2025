# 单轮问答离线下载

在“对话记录”中打开“查看完整问答与引用”，点击“下载本轮问答”。保存为一个HTML网页文件，可用浏览器离线打开。包含该轮问题、已保存回复、记录时间和当时保存的引用摘录；表格与代码保留安全Markdown排版，引用默认完整显示，无需连接服务器。

文件中的主题名称取下载时的当前名称，引用使用问答原来的快照。文件名使用知行、问答日期和轮次编号，不把问题或主题名称放进文件名。未完成或失败的轮次如实显示状态，保留原问题，不伪造回复、不重新发送。离线副本不会自动更新，不含教案、书籍全文、其他问答、账户凭据或恢复资料。

只允许当前登录账户下载本人问答，拒绝跨站请求、无效编号和额外参数。附件禁止缓存与内容类型猜测；文件使用自带CSS及内容安全策略，不依赖网络、脚本、图片、表单或外部资源。问题和引用先转义，回复复用现有安全Markdown，原始HTML与不可信链接不会执行。

每账户每分钟最多6次、全空间每分钟60次下载受理；失败的已受理请求也计数。最多两个并行文件准备位置，始终在准备结束或异常时释放。正文及引用合计最多25万字符，输出最多2MB；超过时可使用已有整包学习资料导出入口。单轮读取复用本人历史详情接口，不新增数据库表、迁移、依赖或服务器导出临时文件；不会切换学习位置、改写教案或消耗AI用量。

检验只使用隔离源码和虚构数据，不读取真实账户、聊天、书籍或敏感配置，不调用真实邮件或AI，不操作原8785服务。
