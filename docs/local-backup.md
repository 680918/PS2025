# 本机成长空间备份与恢复

这项工具保护本机持续使用的成长空间：账户及密码安全哈希、对话与学习主题、学习记忆、原始书籍资料、教案及其版本、学习手册与续读位置。个人网页导出的阅读 ZIP 仍用于阅读和分享其中的学习成果；本工具创建的完整备份用于恢复本机空间，包含该空间内全部账户的私人数据，仅由本机操作者在终端使用。

## 第一次备份与恢复演练

先在运行知行的窗口按 `Ctrl+C`，等服务停止。升级前的旧进程尚未使用新版目录锁，也需要先退出。操作期间停止其他直接使用同一目录的程序。

在自己的 PowerShell 运行：

```powershell
Set-Location 'D:\Personal-Growth-Coach'
$coachPython = 'C:\BCtools\anaconda3\python.exe'
& $coachPython -m api.coach_backup create --output '.\data\coach-backups\my-first-backup.zip'
& $coachPython -m api.coach_backup check '.\data\coach-backups\my-first-backup.zip'
```

第一条创建并核验新备份，第二条独立检查已有包。默认使用 `data/coach-local`；模拟空间或其他位置通过 `--data-dir` 明确指定。同名备份已存在时拒绝覆盖。日常备份可省略 `--output`，自动使用新的时间与随机编号文件名，并显示保存路径。

需要演练恢复时，选择一个从未存在的新目录：

```powershell
& $coachPython -m api.coach_backup restore '.\data\coach-backups\my-first-backup.zip' --target '.\data\coach-restored-trial'
& $coachPython -m api.coach_run --data-dir '.\data\coach-restored-trial' --port 8785
```

用备份时的邮箱和密码登录，核对教案、原始书籍、手册及续读位置。这里没有启用 AI 或发信，可以先免费核对资产。确认后可在启动参数增加 `--ai` 使用自己的本机 AI 配置；模拟空间恢复后启动还需带 `--simulate`。原来的 `data/coach-local` 保留，可停止演练服务，再去掉 `--data-dir` 启动原空间。恢复不是把两个空间的数据合并。

## 保管与范围

备份仅收录三个明确数据库和运行模式标识，并附格式版本、时间及 SHA-256 校验清单。文件不包含 `.env`、邮箱授权码、模型密钥、日志或其他临时文件；原始书籍字节已经在资料数据库内。ZIP 本身未加密，包含账户邮箱、密码哈希及私人学习资料，请存放在自己的安全磁盘，勿上传 GitHub 或作为个人阅读包分享。默认备份及建议的 `coach-restored*` 目录已加入 Git 忽略；自选路径仍需自行保管。可把成功检查的备份再复制到另一块自己保管的磁盘，防止只保留在同一块盘。

每包解包数据最多 512 MB，限当前本机空间格式。创建前后不会改写原账户、资料或学习正文；目录锁文件可以保留，进程退出后锁会自动释放，不靠删除锁文件解除占用。备份、恢复不调用 AI 或邮件。手动操作且不自动删除旧备份，请按自己的保管需要管理磁盘容量。

## 检查与失败保护

创建使用 [Python SQLite 备份接口](https://docs.python.org/3/library/sqlite3.html#sqlite3.Connection.backup)，包含已提交的 WAL 内容；在副本上核对结构和数据库完整性。新版持续服务在应用初始化及运行期间持有目录锁，备份需要独占同一目录，从而避免本版本服务在三个数据库采集期间写入。锁使用 [Windows 文件锁](https://docs.python.org/3/library/msvcrt.html#msvcrt.locking)，其他系统使用 [fcntl 文件锁](https://docs.python.org/3/library/fcntl.html#fcntl.flock)。锁不能约束旧版本或绕过此入口的外部程序。

检查会在临时目录按白名单逐文件读取，核对大小、校验和、运行模式及数据库结构和完整性，限制解包总量，拒绝重复条目、额外路径、符号链接、加密条目及不支持的数据库视图或触发器。校验和用于发现损坏，不是签名认证；仅恢复自己可信来源的备份。个人阅读导出 ZIP 无完整备份清单，会被拒绝。

完整验证通过后才创建新的恢复目录。已存在的文件或目录，即使为空，也拒绝覆盖。恢复期间有未完成标记，文件发布失败时保留该标记，新版服务和启动检查均拒绝使用未完成目录；原空间不被覆盖。失败时保留原空间，改用另一个新目录重新恢复，不把半成品当作可用空间。

恢复副本会清除旧登录会话、密码重置及未完成注册邮件凭证，已验证账户和密码保留；备份后改过密码时，恢复空间仍使用备份时的密码。原来未完成的对话标记为失败，既有消息保留，不会自动重新调用 AI。新邮件功能需要本人在启动时重新配置授权码。本工具提供本机完整备份及新目录恢复，不自动迁移跨版本数据或替代上线部署方案。
