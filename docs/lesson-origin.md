# 教案整理来源追溯

除回看生成教案时的问答外，每条“整理时参考”现可核对对应资料原文，并返回该条引用。详见 [教案引用原文核对](reference-check.md)。

在待确认草稿或已保存教案页，展开“整理来源”可查看生成这份教案时的提问摘要、时间和回复状态。点击“查看整理时的完整问答与引用”进入已有的完整问答页，阅读当时的问题、回复、引用和同一主题的相邻记录。完整页“这轮讨论留下的教案”仍指向当前教案，可以返回继续整理或重温。

来源指的是生成这份教案的那轮对话，不代表知识最早出现的讨论，也不代表AI已经通读所有历史或原书。摘要最多180个字符，较长时标明省略；时间沿用北京时间显示。页面默认折叠，避免挤占教案阅读区。修订教案不改写来源，返回时查看当前版本。

查询和返回均不调用AI、不自动确认草稿、不恢复旧学习进度，也不切换当前主题。需要继续交流时仍明确使用原有主题切换或重温按钮。原对话缺失或无法按同一账户核对时，页面说明暂不可用，教案与已保存引用继续可读；不猜测替代来源。

来源查询按教案与原问答的双重账户归属核对，只提供轮次、时间、状态和有限提问摘要，不返回发送凭证、其他账户内容或完整回复。旧教案不需补写来源表；沿用已有轮次关联，无新依赖、表、迁移或后台任务。

本轮仅使用隔离源码和虚构数据检验，不访问真实账户、聊天、原书或敏感配置，不调用真实AI或邮件。
