# 书籍导读与大文件上传

## 以书名开始

“资料与书籍 → 按书名开始导读”，填写书名、可选作者或版本，建立阅读主题后回到统一聊天框。建议问题只填入输入框，用户明确发送后才调用 AI。也可以直接在聊天中说“我在读《影响力》，请讲讲核心观点和实际应用”。

没有上传原书时，Coach 按通用知识导读，应说明尚未核对原书；先核对有歧义的书名与作者，不能编造原文、页码或通读进度。讲清主要观点、例子、应用和轻量阅读顺序，区分作者观点和延伸建议。不熟悉的书应说明不确定，并请用户补充作者、目录或文字。提示词并不保证模型回答正确，真实 AI 的内容质量需要实际体验核对。

创建阅读主题不调用 AI。同名主题恢复原位置，不覆盖已关联书籍、选段或进度；其他主题保留。可继续讨论、临时换题再回来、整理待确认教案。教案仍需用户在页面明确确认保存。

## 上传原书

- 支持文字型 PDF、TXT、Markdown。单本最多 **100 MB**，每个账户最多 **20 份、原文件合计 300 MB**。
- PDF 最多 **1500 页**、提取文字最多 **200 万字**、单页最多4万字；TXT/Markdown最多200万字。粘贴仍为5万字。
- 上传会先保存原件并提取分段，不调用 AI。之后预览原文、建立学习单元、选择实际片段，再明确点击讲解或发送问题。学习进度记录已讨论、已讲解范围，不等于掌握程度，也不声称一次通读全书。
- 页面提交时显示处理提示，防止重复点击；脚本不可用时仍可使用原生表单。超出单本限制、无法解析表单、扫描版、加密、过多页数及文字超限分别提示。
- PDF 在独立进程内提取，最多60秒、768 MB进程内存，保留解压及复杂页面保护。大文件不保证能在该保护范围内解析；复杂或过长书籍可按章节拆分。后续已支持[逐页本地OCR](local-book-ocr.md)，核对保存后供引用；未提供整本无人值守OCR。未支持EPUB、Word或图片格式。
- 所有原件仍保存在本机资料数据库，提取文字、索引、对话和教案另占磁盘；300 MB不是整个账户磁盘用量。重复上传同内容不重复占用原件额度。
- 个人ZIP导出未压缩内容上限同步提高到512 MB；也可单独下载原件。整库本机备份原有512 MB保护不变，多个账户的累计数据可能需要另行规划备份容量。这些是本机试用限额，尚不是商用云存储套餐。

## 可点击入口

知识资产目录、页面导航、分页和资料操作链接改为带边框、浅绿色背景的按钮式入口；当前目录深绿色白字，鼠标悬停加深，保留键盘焦点和真实链接语义。左侧知识资产入口使用同类样式，窄屏自动换行。
