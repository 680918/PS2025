# 长对话导航与快捷发送

统一输入区增加“回到最新对话”。阅读旧记录或长回复时，点击后回到当前最后一条回复、等待提示或失败状态的开头；仍使用同一个聊天框，不清空输入、不切换主题、不发起请求或调用AI。没有对话时不可用，未加载脚本时隐藏，普通滚动仍可使用。正在等待回复时导航仍可操作。

Ctrl + Enter（Mac可用⌘ + Enter）通过原发送表单提交；普通Enter继续换行。中文输入法组合状态、229兼容事件、按键重复、Shift/Alt组合，以及输入禁用、只读、已在发送或提交按钮不可用时，不触发快捷发送。快捷键复用原表单验证、一次性请求编号、防伪、账户、用量和防重复机制，不创建另一条发送通道，不自动重发；原发送按钮继续保留。

快捷键提示和辅助技术快捷键信息只在脚本启用时提供。新按钮使用原工具栏，窄屏允许换行；仍保持桌面等高三栏和每次回复从开头阅读。无新依赖、表、迁移、浏览器持久存储或后台任务。

检验仅使用隔离源码与虚构长对话，不读取真实账户、聊天、书籍或敏感配置，不调用真实邮件或AI，不操作原8785服务。只有明确发送才可能使用正式环境的AI额度，阅读导航不计入。
