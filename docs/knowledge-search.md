# 在知识资产中找回学过的内容

在“知识资产沉淀”的查找框输入概念、关键词或一句原文，即可查找本人教案的标题、主题及当前正文。已保存教案与待确认草稿分别查找，切换目录时保留关键词，不因查找或打开而改变保存状态；不调用 AI。结果标注匹配字段，正文命中时显示一小段附近原文并高亮匹配文字。片段优先限制在命中段落，避免堆放相邻标题；相近命中不重复堆放同一段。没有结果时可缩短关键词、换一句原文，或切换到草稿目录。

从结果打开教案时显示“查找匹配位置”，使用当前版正文核对匹配数，并展示最多五段附近原文；下方保留完整教案、版本、原有来源、修订、导出与统一对话重温入口。可以返回原状态、关键词和页码的结果；标题或主题匹配但正文没有匹配时明确说明，修订后关键词消失也不会显示旧片段。正文来源片段以原文呈现，完整教案仍使用现有安全 Markdown 排版。

在学习手册中查找可收录教案时也查正文，显示匹配片段，打开后可返回原手册的收录结果和页码。收录仍只接受本人已确认保存的教案，不因为内容命中而自动保存或加入手册。

每次最多 120 字，按输入的整段文字连续匹配，不把百分号、下划线或标点当通配符；英文 ASCII 字母不区分大小写。继续使用每页 20 项及当前排序，先核对账户和保存状态，再从数据库筛选并分页，仅为当页条目读取正文产生有长度上限的片段。空关键词不读取正文或生成片段。结果不会带出完整正文、账户信息或其他人的资料。

这是一项本机文字查找，不提供语义联想、错别字纠正、历史版本全文检索、聊天或原始书籍的跨类型搜索。无需新增数据库表、索引服务、依赖、模型调用或后台任务；仅查询，不改变账户、主题、资料、手册位置、教案内容、版本与状态。查找内容和片段经过 HTML 转义，关键词高亮由受控标签生成。
