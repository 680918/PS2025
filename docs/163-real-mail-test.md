# 第一次真实邮件验证

这一小步只测试“给自己的 163 邮箱发一封邮件 → 在同一台电脑收信并点击 → 网页确认成功”。不开放正式注册、登录，不向其他人发信。

## 先在网易开通

1. 在电脑浏览器打开 [网易邮箱网页版](https://email.163.com/)，登录你自己的普通 `@163.com` 邮箱。
2. 点击页面上方「设置」，进入「POP3/SMTP/IMAP」（部分页面写作「POP/SMTP/IMAP」）。
3. 按网易提示开启包含 SMTP 的客户端服务。若出现身份或短信验证，请你在网易页面自行完成。这属于发件邮箱的安全验证，不是给产品用户开通短信登录。
4. 根据页面提示生成客户端授权码；若服务已经开启，可点击「新增授权密码」。这是给程序发信用的授权码，不是邮箱登录密码。网易提示授权码只显示一次。
5. 保留页面，准备在下面的本机终端中输入。不要把授权码或验证码发到聊天里，也不要截取包含授权码的图片。

页面文字以网易当前提示为准。官方说明：[新增授权码](https://help.mail.126.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac286624f309a1a7089)、[开启客户端协议](https://help.mail.126.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac2a5feb28b66796d3b)。

## 在自己的电脑发送一次

打开 PowerShell，依次运行：

```powershell
Set-Location 'D:\Personal-Growth-Coach'
python -m api.mail_test
```

按窗口提示填写完整 163 邮箱和客户端授权码。授权码输入时不会显示字符；粘贴后回车即可。再核对窗口显示的收件邮箱，输入「发送」才会尝试发送一次。其他输入取消。

不用修改 `.env`，也不用把授权码放进命令行。工具不读取已有 `.env` 或 AI 配置，不保存授权码；本次运行结束后，下次需要重新输入。

若提示 Python 缺少依赖，请按 README 安装项目依赖。若默认端口被占用，可运行 `python -m api.mail_test --port 8775`。

## 收信与确认

保持 PowerShell 窗口运行。在**同一台电脑**上打开网易网页版收件箱，查找「验证你的知行成长教练账号」。没看到时也检查垃圾邮件。

点击邮件里的「验证我的邮箱」，在打开的知行页面点击「确认验证邮箱」。页面应显示「邮箱验证成功」；终端也会显示「测试通过」，随后关闭本次临时服务。链接有效 1 小时，只能确认一次。此测试不会让你登录正式产品。

收到“服务器已接受”提示不等于收件箱已收到。若发送超时或连接中断，工具会保留本机页面供可能已送达的邮件使用，且不会自动重发。先检查邮箱；需要结束时按 Ctrl+C。服务关闭后，旧测试链接不能继续验证，重试须重新运行以获取新邮件。

测试使用系统临时目录中的独立账号和数据库，结束后清理。没有修改项目正式账号、学习记录、现有 `.env` 或默认发信开关。服务仅监听本机；邮件里的 `127.0.0.1` 链接不能在手机或其他电脑上验证。
