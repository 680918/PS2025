# 教案版本对比

在已保存教案的“版本记录”中点击“对比修订变化”，可比较该版与当时的当前版；当前版会与前一版比较。历史版本阅读页也提供入口。对比页可输入另一对已有版本编号，不限于同一页的20条版本；返回时保留原版本目录页码。

页面分别显示两版标题、编号、保存时间和完整阅读入口，正文按原始Markdown逐行标注“+ 新增”“− 移除”和附近保留行。替换计为移除原行并新增对照行，统计不是字数或知识质量评价。重复段落的匹配与换行方式可能影响差异块范围，采用标准库默认行级匹配，不做语义比较，也不保证最少编辑次数。两版正文相同、仅标题不同、选择同一版时均如实提示。

所选编号固定，不自动改为后来的新版。若需要恢复旧版，可打开“阅读本版完整内容”，再通过既有明确确认操作恢复；对比页没有恢复或保存表单，不更改教案、引用、目录或学习位置，不调用AI。

为保证长教案浏览稳定，只展示前400行对照，统计仍覆盖两版完整正文；超出时明确提示，可从上方阅读完整版本。差异仅含修改处前后各两行，不展示全部未改动内容。原始HTML和代码均以文字显示，代码空格和换行保留；行末换行差异也可能形成对照记录。

沿用本人账户、已保存状态、查看限流和禁止缓存策略。无新依赖、数据库迁移、后台任务、脚本或浏览器持久存储；开发检验仅使用隔离源码与虚构数据，不调用真实AI或邮件。
