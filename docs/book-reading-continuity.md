# 原书续读与当前页学习

## 使用效果

- 资料目录中的“继续阅读 · 第N页”回到这本书最后记住的阅读页。普通“阅读全书”同样恢复书签；带明确page参数的原文引用与旧链接按指定页打开。
- 页面并列显示阅读位置与本书最近选段学习位置。阅读页不是Coach已讲解范围，更不表示用户已经掌握。
- 书页成功打开后，停留约1.5秒自动保存阅读位置；也可点击“记住当前页”。保存完成有明确提示，快速离开或网络失败时不能保证最新页已保存；不会在后台自动重试失败请求。
- 页面版本控制避免旧标签覆盖较新的位置。冲突时保留另一窗口的记录，用户明确点击后才能尝试改记当前页。
- “学习当前页”对文字PDF先定位该文件页文字，对TXT/Markdown定位阅读页起始片段。用户再选择片段进入原对话，明确发送才调用AI，不自动讲解整页或整书。
- 扫描页若还没有正文，回到同一文件页并打开识别说明；用户自己点击识别，核对保存后选段。语言、OCR核对和教案确认保存规则不变。本轮没有新增整书或范围批量OCR。

## 数据与运行

原资料数据库幂等新增material_reading_positions表；仅保存资料编号、页码、版本和更新时间，所有读取和写入都由资料归属校验。原件、文字片段编号、引用和学习位置不改写；GET阅读页不写库，自动保存通过有登录、防伪、大小及独立频率保护的POST完成。

原本机完整备份包含资料数据库，因此包含阅读书签；旧备份恢复后可从默认第一页重新记录。个人可阅读导出包仍以正文和既有学习位置为主，不把它当作完整账户恢复备份。原服务需按同一目录重启后使用本功能；不自动重启日常服务。
