# 本人真实 AI 试用

这一步的目标是检验真实交流与教案质量。现有页面仍共用一个对话框；本机已有模拟入口可以保留作对照。当前不公开部署，不开放他人注册。

日常入口与环境区分见[固定入口](daily-use.md)。日常默认端口现为 8785，下文显式参数仍然有效。

## 先做启动检查

打开自己的 PowerShell，执行：

```powershell
Set-Location 'D:\Personal-Growth-Coach'
python -m api.coach_run --check --ai --register --port 8785
```

如果电脑的 `python` 与项目运行环境不同，可以将上面 `python` 替换为 `& 'C:\BCtools\anaconda3\python.exe'`，后续也使用同一个 Python。

检查会加载运行依赖，核对数据目录模式、端口和基本 AI 配置。它不会启动网页、创建账户或数据库、索取邮箱授权码、发送邮件或调用 AI；不会显示密钥，也不改写 `.env`。未指定 `--ai` 或选择 `--simulate` 时不读取 AI 配置。

检查通过只表示上述本机条件满足，不代表密钥有效、模型可用、余额充足或回答质量合格。文件夹的实际写入权限在正式启动时确认，端口也可能随后被其他程序占用。

- 依赖提示：使用同一个 Python 执行 `python -m pip install -r requirements.txt`。
- AI 配置提示：仅在本机检查已有 `.env` 中的 `DEEPSEEK_API_KEY` 与 `LLM_TIMEOUT`（1–60 秒）；不要在聊天里发送内容。不要覆盖已有配置。
- 端口占用提示：先核对 8785 是否已有日常服务运行；日常建议保持固定入口，独立测试才明确指定另一端口。记录仍由数据目录决定。
- 模式冲突提示：模拟默认使用 `data/coach-simulated`，真实默认使用 `data/coach-local`，不要手工修改 `.coach-mode` 或把两者混用。

## 正式启动本机试用

首次在持续数据空间注册：

```powershell
python -m api.coach_run --register --ai --port 8785
```

仅在自己的终端输入本人 163 邮箱和客户端授权码；授权码隐藏输入，只保留于本次进程，不写入配置或 GitHub。打开终端显示的地址；注册、点击发送邮件、从本人邮箱确认，再登录。邮件发送仍由你在网页主动触发。此前临时测试账户不会自动迁移；如果已经在 `data/coach-local` 注册，无须重复注册。

之后启动已有账户：

```powershell
python -m api.coach_run --ai --port 8785
```

停止按 Ctrl+C。默认 `data/coach-local` 保留账户、聊天、资料与教案，已被 Git 忽略；重启使用同一目录即可。只改变端口不会更换账户空间。不要删除数据目录。

## 按一个完整学习过程体验

更完整的最新版路线见[本机试用验收路线](local-trial-acceptance.md)，包括教案修订对比、引用原文核对、导出与结束重温；已有账户继续使用原登录和数据目录。

1. 自由聊几句，再说“我想学习……”，观察输入框上方是否显示正确主题；再到“我的学习”核对进度与下一步。
2. 上传一份自己熟悉的短资料或粘贴几段文字，选定后在原对话提问；展开引用，对照原文是否支持回答。上传和查看不调用 AI。
3. 临时聊其他事，再进入“我的学习”点击继续学习，观察能否自然回到原主题。
4. 说“请把刚才的知识点整理成便于重温的教案”。预览是否有知识点、例子和可用练习，按需修改，确认后到知识库查阅、导出、回到对话重温。
5. 退出、停止并重新启动，再登录，确认聊天、资料、教案和学习位置仍在。

有问题时告诉开发助手“进行到哪一步、页面提示什么、期望怎样”；无需填写评分表，也不要附上密钥、授权码或带验证凭证的邮件链接。

启用真实 AI 后，点击发送、继续学习或整理教案会请求已配置服务，可能产生费用；输入消息、有限最近对话、当前主题及相关资料片段/教案上下文可能发给该服务。对话输入区会显示当前服务状态并可打开 AI 用量页；详细学习和续学入口在“我的学习”。查看页面、上传、检索、预览、确认保存和导出不调用 AI。系统不自动重试；失败不等于服务商一定未计费，是否再次发送由用户决定。

本地关键词检索最多提供 6 个片段，不能据此声称通读整本书。当前已支持书籍学习单元与逐段接续、教案版本记录与恢复、版本对比及原文核对；扫描 PDF 已支持逐页本地 OCR，核对保存后供引用；尚不支持无人值守整书 OCR 或整书课程生成，跨设备同步与公开商用尚未提供。当前重点是实际验证完整学习流程的质量，再根据体验改进。
