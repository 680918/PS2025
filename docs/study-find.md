# 按学习内容找回主题

“我的学习”共用一个查找框，查找当前保存的主题名称、已讨论内容和下一步。即使忘记主题名称，也可用记得的知识点找回学习位置；每张结果卡标明匹配位置，原有进度、下一步、资料、只切换与继续学习入口保留。

采用连续字词匹配，不将百分号、下划线或引号当通配符或查询语法。沿用主题标题的全半角、大小写与空白规范化，三个字段分别匹配，不把相邻字段拼成虚假的短语。每页10项，翻页保留关键词，“查看全部主题”清除查找并回到第一页。

查找范围是目前保存的学习摘要，不代表搜索完整聊天、书籍原文、旧版学习记录或已掌握的知识。完整问答仍可到“对话记录”查找，书籍原文使用“资料与书籍”中的查找。

读取仅限登录账户，查询与翻页不调用AI、不修改当前学习主题、资料或续学位置，不使在途请求过期。明确点击“只切换主题”或“继续学习”才走原有受保护流程；后者可能调用已配置的AI。

本轮不增加依赖、表、迁移、搜索索引或后台任务。桌面与窄屏沿用既有主题目录布局。检验仅使用隔离源码和虚构数据。
