# 常用教案收藏

在已保存教案页点击“收藏为常用教案”，以后可以从左侧知识资产沉淀或教案目录的“常用教案 · 我的收藏”快速进入。支持标题、原学习主题及当前正文的文字查找，每页20份；打开教案可返回原关键词与页码，也能沿用原来的重温、修订、版本及导出入口。

收藏引用原教案编号，不复制正文、资料或版本。修订和恢复旧版后显示当前教案；取消收藏不删除原教案，不影响学习手册。草稿必须先明确确认保存，才能收藏。收藏和浏览不调用AI、不增加受理次数，不改变学习位置或资料选择。

新表仅保存账户、教案编号、选择状态和操作版本。历史数据库启动时创建空表；取消后保留操作版本以防止旧页面在多次收藏/取消之后覆盖新选择。每次提交绑定会话、目标教案、版本及明确的选择状态；事务内核对账户归属和已保存状态，重复旧提交或并发冲突要求重新查看，不自动切换状态。

整库备份与恢复包含收藏标记。个人阅读导出仍沿用已有已保存教案和手册范围，不因收藏额外复制一份；收藏标记不是额外的知识正文或离线同步功能。不增加依赖、后台任务、短信或外部存储费用。

只用隔离源码和虚构资料检验，不读取真实账户或原书，不调用真实邮件与AI，不停止原8785服务。
