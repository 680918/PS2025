# 单份教案离线阅读版

在已保存教案页点击“下载阅读版”，直接取得一个HTML文件，可在本地浏览器打开重温。文件包含下载时的当前标题、正文、版本、北京时间修订时间、原学习主题、最初整理时的引用，以及存在时的单元生成范围。表格和代码沿用知行的排版，无须另装Markdown阅读软件。

阅读版明确标注这是静态副本，不会跟随之后的修订更新；引用表示最初整理时的参考，不代表用户后来添加的内容已经得到原书核实。草稿和已移出草稿不提供这个入口，也不能通过地址下载为已确认教案。

原Markdown下载地址和正文保持兼容，页面按钮改为“下载 Markdown”以便区分；批量ZIP导出继续使用原入口。阅读版不包含其他问答、其他教案或整本原书，也不修改在线教案、版本、学习位置或收藏状态。

生成在本机完成，不调用AI、邮件或外部资源，无新依赖、数据表或迁移。HTML内嵌样式，正文使用既有禁用原始HTML、图片与链接的Markdown渲染，元数据与引用按纯文字转义，设置离线内容安全策略，文件名只由固定文字、教案编号和版本组成。

登录、账户归属、同源来源、短期限流、共享两份导出准备并行限制、源文字与最终文件大小限制共同沿用现有下载方式。读取失败会提供普通提示，不暴露内部位置，也不阻塞之后的下载。

检验仅使用隔离源码和虚构账户、教案与引用，不读取本人真实学习内容或敏感配置，不调用真实AI或邮件。
