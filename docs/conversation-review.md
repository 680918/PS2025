# 对话记录回看与查找

左侧“我的空间”增加“对话记录”，可查看本人已有问答，按消息或回复中的关键词查找，并按存储时关联的学习主题筛选。“我的学习”的每个主题也提供“回看主题对话”，不需要先切换当前主题。

## 使用方式

1. 打开“对话记录”。不填写关键词可以逐页回看；填写关键词查找你当时发送的消息和 Coach 已保存的回复。每页最多 20 轮，按轮次从新到旧排列。
2. 结果显示日期、主题、回复状态与附近原文；点击“查看完整问答与引用”，阅读完整消息、带表格和代码框的回复，以及当时保留的实际引用。
3. 完整页可查看该主题的上一轮、下一轮；返回时保留原来的关键词、主题和结果页码。相邻记录不必都匹配关键词，页面会如实提示当前轮次是否匹配。
4. 本轮如果产生教案，显示当前教案的入口及“草稿待确认”或“已保存”状态。普通回看不保存草稿、不修订教案；已放弃的草稿不重新出现。
5. 想继续交流时，明确点击“回到这个学习主题”，恢复该主题当前保存的进度与资料，回到原统一聊天框。切换本身不调用 AI；之后发送问题或点击续学才调用已启用的 AI。未分类记录不猜测主题，也不提供自动关联或重发操作。

查找、阅读、翻页和查看引用不调用 AI，也不改写学习位置、聊天内容、记忆、教案、选段或已讲解记录。正在回复时仍可回看，切换操作沿用原来的忙碌保护。失败或未完成的轮次保留原消息；刷新与查看都不会自动重试。

## 数据与边界

- 只查服务端当前登录账户的聊天消息和已保存回复；不把书籍全文、教案、引用摘录或主题标题混入聊天正文查找。原文与教案继续使用各自入口。
- 查询按原文字词匹配，最多 120 字，不含内部换行和控制字符；英文 ASCII 字母不区分大小写，百分号、下划线、引号按普通文字匹配，不支持语义或同义词搜索。
- 所属主题取已有数据库归属，不重新用 AI 分类。早期或独立整理的未分类记录保持未分类。主题标题显示当前名称；引用保留当时的书名、位置与摘录，不随当前资料选择或教案修订改写。
- 每轮完整问答使用原本存储的内容；不会扩展模型的历史上下文预算。历史回看页没有新的聊天输入框，继续交流始终进入统一对话。
- 下拉菜单显示最近更新的 100 个学习主题，当前筛选的较早主题仍保留；其他主题可从“我的学习”的回看链接进入。查找范围可以选全部或未分类记录。
- 新的对话或后台完成的回复可能改变实时查找结果；翻页不是冻结的数据副本。
- 详情的相邻轮次限制在同一存储主题或同为未分类，不跨其他账户，也不假定它们是原始时间线上连续的轮次。
- 特殊文字先转义，回复使用既有安全 Markdown；原始 HTML、脚本、图片和不可信链接不会执行。页面禁止缓存，设置不传递来源和禁止嵌入的响应头，并有查看次数限制。关键词位于本机 URL，可能保存在浏览器历史。
- 显式切换复用已有主题操作及会话绑定的 CSRF，跨站、篡改主题和其他会话的旧表单均受原有保护。回看旧问答不会恢复历史时刻的进度或覆盖现在的学习成果。

实现使用已有对话表和主题索引，无新增依赖、数据库迁移、外部搜索服务或后台任务。列表只返回有长度限制的片段与显示字段，不返回单次请求凭证；详情按账户读取单轮内容、实际引用、相邻轮次及本轮教案状态。

## 本机体验

原服务重启后，继续使用原来的数据目录和邮箱账户。进入左侧“对话记录”，搜索以前聊过的关键词；从旧主题的完整问答明确回到该主题，确认统一对话右侧恢复当前进度和所选资料。无需重新注册或重新配置邮箱。
