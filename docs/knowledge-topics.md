# 知识资产按主题分类浏览

已保存教案、待确认草稿、常用收藏和已移出草稿目录增加主题选择。先选主题，再点击“查找”，可在该主题内按标题、主题和当前正文查找。分页、打开教案和返回目录保留主题、关键词和页码；切换目录保留主题和关键词，从第一页开始；“清除查找”保留主题，“查看全部主题”保留关键词。没有匹配时提供恢复查找范围的入口。

使用教案整理时保存的主题原文精确分类，不要求补填标签，不合并近似名称，不将主题改名回写旧教案。名称相近、大小写不同的主题可以分别存在；历史主题不是当前学习主题编号。筛选只影响目录，不切换学习位置、资料或重温状态，不修改正文、版本、收藏或教案状态，不调用 AI。确认、修改、重温及导出仍使用原入口和保护；筛选不限制实际导出的范围，导出需在原导出页面明确选择。

每个目录的主题计数按本人、当前保存状态及收藏范围统计，独立于关键词；计数不是掌握程度或查找命中数量。已移出草稿不会混入已保存目录。每页仍显示20项，先限定主题与关键词再分页。主题选项最多显示最近有记录的200个主题；已有链接选中的较早主题也保留，可正常分页。选择全部主题时文字查找仍覆盖所有本人记录。目录计数与条目分别读取，其他页面同时确认、移出或收藏时，刷新后可看到最新结果。

页面参数限定120字，不接受重复主题参数、换行或控制字符；SQL使用参数绑定，所有主题名称、链接和表单值按上下文转义。空主题表示全部，查找和主题名称均按本机记录处理，不提供跨账户或语义查找。没有新增表、依赖、后台任务或收费服务。

开发检验仅使用隔离源码、虚构账户和资料，不访问真实账户、对话、书籍或敏感配置，不调用真实邮件与AI，不操作原8785服务。
