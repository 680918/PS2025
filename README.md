# Personal Growth AI Coach

长期学习陪伴与个人知识积累工具。CI protected by GitHub Actions.

## 最新入口：账户与持续对话

统一对话、当前学习主题、讨论进度和“继续上次学习”已接入独立本机账户空间。模拟体验：

```powershell
Set-Location 'D:\Personal-Growth-Coach'
python -m api.coach_run --simulate
```

打开 <http://127.0.0.1:8784/web/register>。模拟邮件从 <http://127.0.0.1:8784/web/trial-mailbox> 确认。模拟 AI 不收费、不调用外部服务，记录保留。真实本人注册和 AI 体验使用 `python -m api.coach_run --register --ai`，之后使用 `python -m api.coach_run --ai`；需要本机已有 AI 配置，仅发送时调用计费服务。此前临时工具的账户不会迁移，需要在持续数据空间注册一次。

聊天、主题学习共用一个输入框；转题不清除学习位置。现已接通资料上传与引用、教案草稿确认保存及知识库查阅重温；用户可以要求整理教案，Coach 也可以提出草稿，始终经用户预览确认后保存。参见 [资料与知识库说明](docs/materials-and-knowledge.md)。更新后先安装 requirements.txt，以使用新增 PDF 依赖。账户数据、对话均按用户隔离且保存在本机，默认数据目录已加入 Git 忽略。详见 [统一对话与启动说明](docs/coach-dialogue.md)。本步自动检验使用假 AI，真实 AI 回复质量仍需实际体验；尚未公开部署。

真实试用前可运行 `python -m api.coach_run --check --ai --register --port 8785`；仅检查本机条件，不发信、不调用 AI。通过后去掉 `--check` 启动。端口可更换，记录仍保存在同一本机账户空间。详见 [本人真实 AI 试用步骤](docs/real-ai-local-trial.md)。

左侧“知识资产沉淀”现可选择导出教案、草稿、聊天与引用、学习位置和原始资料。下载包含可直接打开的阅读目录，Coach 内内容继续保留，不调用 AI；详见 [个人学习资产导出](docs/personal-asset-export.md)。

**下方 `api.run` 是保留的旧开发入口，其禁用登录与旧学习页面描述不适用于以上新入口。**

## 启动网页

使用 Python 3.12。下面以本机的项目目录为例；如果项目放在其他位置，请替换路径。

在 PowerShell 中进入项目目录：

```powershell
Set-Location 'D:\Personal-Growth-Coach'
```

首次使用时安装依赖：

```powershell
python -m pip install -r requirements.txt
```

配置 AI 密钥。如果已经有 `.env`，保留并编辑现有文件。下面的命令仅在文件不存在时复制示例：

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

在 `.env` 中填写自己的 `DEEPSEEK_API_KEY`。模型和其他配置可参考 `.env.example`；密钥保留在本机，不要上传 GitHub。修改配置后需要重新启动。

每次启动网页只需运行：

```powershell
python -m api.run
```

保持这个窗口运行，在浏览器打开 <http://127.0.0.1:8000/>。停止时回到 PowerShell 按 **Ctrl+C**。

未配置密钥也可以打开首页；生成课程、AI 对话等功能需要有效密钥。启动入口仅监听本机地址。

## 常见启动问题

- **提示缺少依赖**：在项目目录重新执行 `python -m pip install -r requirements.txt`。
- **8000 端口被占用**：运行 `python -m api.run --port 8001`，打开 <http://127.0.0.1:8001/>。
- **提示配置格式不正确**：检查 `.env` 中的数值设置，例如 `LLM_TIMEOUT` 应为整数。
- **提示无法初始化数据库**：检查数据目录是否为文件夹、是否有读写权限，以及磁盘空间。
- **网页打不开**：检查启动窗口是否仍在运行、是否显示启动错误，以及浏览器地址中的端口是否一致。

运行 `python -m api.run --help` 可以查看可选参数。

## 数据位置

默认使用项目目录中的 `data` 文件夹保存现有 SQLite 数据库。启动入口不会因命令窗口位置不同而改变默认数据目录，也不会主动清空已有数据库。

需要使用独立的验证数据时，可以指定其他目录：

```powershell
python -m api.run --data-dir .\data\web-smoke --port 8001
```

相对路径以当前命令窗口所在目录为准。切换数据目录会进入独立的数据空间；原目录中的学习记录仍然保留。

另已增加独立的 163 加密发信模块和验证邮件模板，默认关闭。已完成模拟测试和下述一次真实邮件人工验收；网页尚未调用发信模块。准备方法及边界见 [163 验证邮件发送](docs/163-mail-sending.md)。

邮箱验证确认页已接入：打开邮件链接后先确认，再显示成功或失效提示。此页不会创建登录会话，网页注册、登录与重新发送入口仍未开放。页面效果、测试和本机启动的日志设置见 [邮箱验证确认页](docs/email-verification-page.md)。

已提供 `python -m api.mail_test`，用于向自己的 163 邮箱发送一封真实验证测试邮件。授权码在本机终端隐藏输入，不写入文件，不改现有 `.env`，只使用临时测试账号。操作步骤见 [第一次真实邮件验证](docs/163-real-mail-test.md)。2026-10-16 已完成一次真实收信、点击及服务端确认的人工验收；这不代表正式注册或登录已开放。

注册填写检查与邮箱验证准备页说明见 [注册表单预览](docs/registration-form-preview.md)。真实邮件测试工具与注册预览保持独立，提交注册预览不会触发测试工具或真实发信。

注册预览已增加 [防伪提交保护](docs/registration-form-protection.md)：从注册页打开的有效表单才能提交，过期、被篡改或跨站提交会提示重新打开页面。正常填写、字段纠错与有效期内的多标签页可继续使用；通过后保存待验证申请，不创建正式账户或发邮件。

注册预览现已增加 [请求次数限制](docs/registration-rate-limits.md)：同一来源每分钟最多提交 10 次、打开注册页 30 次，另有服务进程总量上限。超限显示剩余等待时间，不回显填写内容；到期后可继续。此能力用于本机单进程，本机启动不信任任意代理来源头，尚不代表可以公开部署。

另已提供内部的 [待验证注册申请保存能力](docs/pending-registration-foundation.md)：只保存密码安全哈希，申请默认 1 小时过期，重复申请不能替换尚有效的内容或覆盖已有账户。现已连接网页保存；不会自动发信或创建正式账户，详见 [网页申请保存](docs/registration-application-saving.md)。

内部申请现已支持 [浏览器归属校验](docs/registration-browser-binding.md)：新申请与归属凭证摘要一起保存，查询及重发需提供正确凭证；仅有申请编号不能操作带绑定的申请，也不能认领旧申请。成功开户或过期清理时归属一并失效。现已通过专用 HttpOnly Cookie 接入网页；等待页只显示部分遮盖的邮箱与到期时间，不输出原始凭证或密码哈希。

内部注册申请现已可绑定一次性邮箱链接：有效确认后，在同一事务内创建账户、保存原申请的密码哈希、标记邮箱已验证并清除申请。过期、重复确认及已有账户不会被重复建号或覆盖；重发不延长原申请期限。

已接上 [注册专用邮箱确认页](docs/registration-confirmation-page.md)：打开链接只展示确认页，点击确认后才开户，并显示成功、失效或稍后重试提示。注册表单已保存带归属的申请，但尚未接通 SMTP，不建立登录会话；邮件链接仍仅可由受信任内部流程生成。

已提供 [注册邮件状态与失败重试保护](docs/registration-mail-delivery.md)，并接上 [等待页邮件操作](docs/registration-web-mail.md)：显式配置后可首次发送、查看状态，并在明确失败和冷却期结束后主动重试。刷新不发信，超时、中断或结果落库失败不会盲目重发。当前验收使用独立临时数据与模拟邮件，普通启动仍不启用网页发信，不读取已有 SMTP 环境开关自动发送。

本轮新增独立的账户试用入口，支持注册、邮箱确认、登录、本人欢迎页和退出。使用临时数据库，不改动现有学习资料。登录后采用 [统一对话工作区](docs/unified-conversation-product.md)：聊天、主题学习、书籍讨论共用一个输入区，知识库与资料管理另有标识；持续对话、资料上传和教案确认保存已在本文顶部的新入口中接通。旧的按用户编号操作的开发接口不挂到这个入口中。

```powershell
python -m api.account_test --simulate
```

上述命令使用模拟邮件。若要仅向本人 163 邮箱进行真实注册验收，运行 `python -m api.account_test`，在本机终端隐藏输入授权码，再由本人在网页点击发送。完成注册、验证、登录与退出后，回终端按 Ctrl+C，查看结果并清理临时数据。详细操作与边界见 [账户试用说明](docs/account-trial.md)。默认端口 8782；这与 `python -m api.run` 的旧开发页面分开。

### 本机邮箱找回密码

登录页已接入邮箱找回与一次性链接重置，成功后撤销旧登录状态并保留学习资产。发信仍需本机显式 `--register`，不保存授权码。操作、冷却与异常提示见 [邮箱找回密码](docs/password-recovery.md)。

### 我的学习记忆

统一对话支持明确“请记住……”保存学习目标或偏好，后续交流可参考；左侧可查看、修改和确认删除，资料导出支持选择记忆。原话保存不调用 AI，不从聊天或书籍中自动推断画像。详情见 [长期学习记忆](docs/learning-memory.md)。

### 我的学习与多主题续学

统一对话支持按主题分别保存进度和关联资料。左侧“我的学习”可新建、查找、切换与明确点击继续学习。目录和切换不调用 AI，续学沿用已有 AI 服务。旧的最后学习位置兼容保留，详细行为见 [多主题学习](docs/multi-topic-learning.md)。

### 已保存教案的修订与版本

已保存教案支持修改标题和正文、查看版本记录，以及明确恢复旧版。每次修订保留原文，重温和导出使用当前版本；编辑不调用 AI。操作、冲突处理与存储边界见 [教案持续修订](docs/lesson-revision.md)。

### 书籍选段导学

资料页支持按文字片段、PDF 文件页码定位，选中后在统一聊天框讲解和提炼。每个主题保留书籍与选段，右栏显示真实位置；浏览和选段不调用 AI，明确提问后才调用。当前以单个已提取片段为资料来源，操作与边界见 [书籍选段导学](docs/book-section-study.md)。

书籍连续导学支持按实际 PDF 页码或文字片段建立可修改的学习单元，在统一聊天框逐段讲解、显示引用与讲解进度。详见 [书籍学习目录与连续导学](docs/book-study-directory.md)。

学习单元可分批整理已讲解原文为教案草稿，确认后保存，并在原单元集中调阅、重温、修订与导出。详见 [单元教案](docs/unit-lessons.md)。

已保存教案可以组织成学习手册，支持收录、排序、逐章阅读、记住章节位置并跨次续读、重温和整册 HTML/Markdown 导出，整理与记住位置不调用 AI。详见 [学习手册](docs/learning-booklets.md)。开发采用 [自主开发与检验后提交](docs/development-workflow.md) 流程。
